# 후속 점검 — 날짜와 구조화 제목

대상은 한입 건강이다. 기존 356개 HTTP 관찰의 `checkedAt`을 유지해 재분석했으며 전체 URL을 새로 조회했다고 보고하지 않는다.

## 확인 결과

- Article/BlogPosting 누락, schema URL 불일치, 제목 누락, 발행일·수정일 파싱 실패, 수정일이 발행일보다 앞선 사례: 이번 저장 관찰에서 0건.
- 구조화 제목에 HTML entity가 남은 글: 126개. JSON 구문 오류와 구분하며 검색 노출 실패라고 확정하지 않는다.
- `/282` 현재 공개 DOM에서 headline의 `&middot;`와 화면 제목의 `·` 차이를 직접 확인했다. 발행일은 `2024-03-26T00:54:50+09:00`, 수정일은 `2026-10-09T22:30:12+09:00`이다. 해당 날짜는 제공자 메타데이터이며 원문 검토일 또는 독립적으로 검증한 내용 개정일로 대체하지 않는다.
- 전체 글의 실제 개정 이력, 원문 확인일, 구조화 데이터 의미와 공식 검색엔진 검사는 아직 완료하지 않았다.

## 성능 후보 적용과 복구

목차 앞에 고정 공간을 예약하는 후보를 관리자 스킨에 시험 적용했다. 실제 `/282`의 목차 높이가 251.6875px인 상태에서 252px 최소 높이를 추가하면 padding을 포함한 높이가 288px로 늘어났다. 폭·목차 수에 따른 빈 공간 가능성 때문에 후보를 제거하고 이번 작업 직전 원본으로 복구했다.

복구 후 관리자 편집 내용은 백업 원본과 동일하고, 쿼리 없는 공개 `/282`에서 `min-height:0px`, 목차 높이 251.6875px를 확인했다. 고정 높이 후보는 저장소의 배포 코드에 반영하지 않았다. 화면 밀림의 실제 기여도를 추가 측정하지 않았으므로 원인을 목차 하나로 확정하지 않는다.
