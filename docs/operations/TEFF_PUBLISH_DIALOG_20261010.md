# 테프 발행창 실패와 공통 준비 상태 보강

대상 실행: https://github.com/ansqhd5774-Choi/nhunnhun_blog/actions/runs/37969880112 .
선택 원고: `direct-teff-nutrition-gluten-20261010`.

## 직접 확인된 원인

실패는 `E_PUBLISH_DIALOG_UNAVAILABLE`, 최종 제출 전이며 submitting 원장은 없었다. 실제 러너의 남아 있는 편집기에서 제목은 빈 값이고 `red` 오류 표시가 있었다. 태그10개는 완료됐으며 파일 업로드 대기는0이었다.

같은 편집기에서 원고 제목을 입력·blur한 뒤 완료 버튼을 한 번 눌렀을 때 발행창이 표시됐다. 최종 공개 발행은 누르지 않고 취소했다. 따라서 이 실행의 직접 원인은 발행창 진입 시 제목 누락이다. 제목이 앞선 어느 입력·렌더 단계에서 사라졌는지는 이전 로그로 확정할 수 없다. 태그10개 제한이나 단순 버퍼링을 원인으로 단정하지 않는다.

기존 신규 경로는 이미지 업로드·모드 전환 전에 제목을 입력하고, 실제 제목 일치 검사는 발행창이 열린 뒤에만 수행했다. 수정 경로도 HTML 모드 전환 전에 제목을 입력했다. 준비 상태 검증 위치가 뒤에 있어 필수 입력 누락을 발행창 timeout으로 보고했다.

## 변경

- 신규·수정 모두 본문과 태그 입력이 끝난 뒤 제목을 입력하고 blur한다.
- 제목 일치·빈 값/오류 표시·신규 태그 완료·버튼 표시/활성/가림을 250ms 간격으로 읽는다. 정상 상태가1초 연속 유지된 뒤 진행한다. 상태가 바뀌면 안정화 시간만 초기화하며 제목 입력이나 클릭을 반복하지 않는다. 준비 대기는 최대15초다.
- 클릭 직전 다시 상태를 확인하고 발행창 표시를 최대30초 기다린다. 이미 열린 창은 다시 토글하지 않는다.
- 준비 실패와 발행창 표시 실패를 별도 코드/안전 로그로 기록한다. 제목·본문·태그 문자열·이미지 URL·인증정보는 이 로그에 포함하지 않는다.
- 최종 공개 발행, submitting 기록, 중복 방지, 공개 검증 절차는 유지한다. 최종 제출 재시도를 추가하지 않는다.
