# 과거 원고 강조·사진 후속 수정

현재 공개 본문을 먼저 대조하고, 실제 보완이 필요한 다섯 글만 기존 숫자 URL에 수정했다. 과거 자동 검사 실패 자체를 공개 장애로 취급하지 않았다. 기존 `submitting` 기록을 삭제하거나 재사용해 무조건 재제출하지 않았다.

## 원인과 재발 방지

- 과거 source의 단독 `mark`는 새 직접 작성의 `mark+strong` 계약과 달랐다. 새 제출 전 검사 보호는 유지하며, 이번 문구 선택은 작성자가 검토했다. 검사기가 강조 문장을 만들어 넣지 않는다.
- 깻잎 Commons 파일명에 작은따옴표가 포함되어, 정상적인 이중따옴표 href도 기존 추출기가 거부했다. 시작·끝 따옴표를 같은 구분자로 인식하도록 최소 수정했다. 작은따옴표 파일명·단일따옴표 속성·다른 원본·잘못 닫힌 속성 회귀 사례를 추가했다. 실제 잘못된 출처를 허용하거나 스키마를 완화하지 않았다.
- 고등어의 물속 무리 사진을 신선한 고등어로, 필렛 사진을 옆모습으로 설명한 오류를 실제 사진 대조로 찾았다. 구운 고등어를 대표 사진으로 배치하고 나머지 설명을 관찰 가능한 내용으로 고쳤다. 사진만으로 신선도·가열 중심온도를 판정하지 않는다.
- 다른 글의 실제 제출 실행이 끝난 뒤 다음 수정 PR을 병합한다. 한 번에 한 원고만 표준 자동 전달 경로로 적용하고 공개 검증까지 추적한다.

## 검증 범위

사진은 Commons 공개 이미지와 저작자·라이선스를 직접 확인했다. 사진 원본은 변경하지 않고 표시 크기만 조정하며 원본과 라이선스 링크를 본문에 보존한다. 선택 원고 준비 PASS는 구조 검사이며 독립적인 의학·영양 감수를 의미하지 않는다.

다섯 글 모두 표준 수정 SUCCESS 및 실제 PUBLIC_VERIFIED/updated를 확인했다. PC 1440px·모바일 390px에서 가로 넘침0, 본문 사진3장·오류0, 대표 이미지 일치를 확인했다. 계란의 세 번째 사진은 화면 밖에서 지연 로딩되며 해당 위치로 이동한 후 실제 로딩을 추가 확인했다. 수정 당시 공개 화면 관찰은 GitHub 러너 결과와 별도로 보존했다.

로컬 전체 회귀: 306/306 PASS. 사진 주소 처리의 집중 회귀: 47/47 PASS. 새 글 추가로 과거 151건 원장의 역사 상태를 성공으로 일괄 변경하지 않았다. 당시 렌더러와 공개 문구가 일치했던 /179·/323·/269는 반복 제출하지 않는다.

32개 운영 항목의 기존 합계 21완료/10미완료/1보류는 유지한다. 이번 다섯 글의 수정으로 전체 과거 글의 출처·날짜·의미·이미지 감수가 완료되는 것은 아니다. 전체 이미지 alt 누락61곳, /264의 과거 PDF, /237의 물질명 혼동, 글별 색인·IndexNow·성능 후속 항목은 별도 미완료다.
