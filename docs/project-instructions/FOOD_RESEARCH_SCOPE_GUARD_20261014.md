# 음식 조사 범위 메모 — 통합됨

적용일: 2026-10-14

이 파일은 가시진흙새우 `/440` 조사 범위 부족 문제를 분석하면서 임시로 만든 보조 문서다.

현재 음식 조사·작성 기준은 `PROJECT_INSTRUCTIONS_FOOD_R8.1.txt`의 **6. 조사·근거·수치·날짜**와 **9. 작성·검토·공통 검사**에 통합했다. 이 파일은 별도 Gate·추가 검사·추가 재검사 기준으로 사용하지 않는다.

핵심 원칙은 다음뿐이다.

- 공식 자료를 우선하되 공식 자료만으로 조사를 제한하지 않는다.
- 음식명·표준국명·학명·이명·해외명으로 실제 독자 질문에 필요한 정보를 충분히 찾는다.
- 지역별 맛·식감·식용법·제철·어획·유통 자료는 해당 지역 범위를 밝혀 활용한다.
- 근거 범위가 다르면 유용한 자료를 버리는 대신 적용 범위를 정확히 표시한다.
- 학명이 다른 종의 영양 수치·효능만 대상 종의 직접 값으로 대입하지 않는다.
- 표준 영양표가 없다는 이유로 조사를 끝내거나 `자료 없음`을 글의 중심으로 만들지 않는다.
- 저장 전 검토와 preflight는 활성 음식 지침대로 한 번씩 수행하며 동일 source·SHA에 같은 검사를 반복하지 않는다.
