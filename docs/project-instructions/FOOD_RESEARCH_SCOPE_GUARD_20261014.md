# 음식 조사 범위·종 일치 재발 방지 규칙

적용일: 2026-10-14
대상: `nhunnhun.tistory.com` 음식 direct/SP1 작성·전면수정

## 1. 조사 중단 금지
- 공식 영양 DB에서 대상 식품의 표준 100g 성분표가 바로 나오지 않는다는 이유로 조사를 종료하지 않는다.
- 음식명뿐 아니라 **표준국명·학명·주요 이명·해외명**으로 검색 범위를 확장한다.
- 최소 조사 축은 공식기관/공공 DB, 전문기관·수산/농업 연구자료, 국내외 원문 연구다.
- 영양·성분 자료가 부족하면 일반성분, 아미노산, 지방산, 무기질, 색소·향미·기능성 성분, 식품학적 특성, 어획·유통·식용 근거까지 주제에 맞게 확장한다.
- 검색 결과가 부족하다는 결론은 **확장 검색을 수행한 뒤**에만 쓴다. `표준 영양표 없음`과 `직접 연구 없음`을 같은 뜻으로 처리하지 않는다.

## 2. 종 일치 Gate
- 수치·성분표·연구 결과를 본문에 넣기 전에 출처의 **국명과 학명**을 대상 식품과 대조한다.
- 국명이 비슷하더라도 학명이 다르면 대상 식품의 직접 수치로 사용하지 않는다.
- 같은 속·과·일반 새우류 자료를 쓸 경우 `참고 비교`라고 명시하고 대상 종의 직접 값처럼 쓰지 않는다.
- 예: `가시진흙새우 = Argis toyamaensis`, `가시발새우 = Metanephrops thomsoni`. 두 종의 성분표를 서로 대입하지 않는다.

## 3. 근거 범위 표시
- `DIRECT`: 대상 종/품종/가식부를 직접 분석한 자료.
- `REFERENCE`: 같은 식품군의 일반 영양·조리·안전 원리. 대상 종의 고정 수치로 사용 금지.
- `NOT_APPLICABLE`: 이름이 유사하지만 다른 종·다른 가식부·다른 제형의 자료.
- 작성자는 핵심 수치와 효능 문장을 저장 전에 위 세 범주로 구분해 검토한다.

## 4. 음식 ② 효능·영양 항목 작성
- `공식 표준표가 없다`는 한계 설명만으로 ②를 채우지 않는다.
- 직접 성분 연구가 있으면 구체적인 성분·역할·식사 활용을 먼저 쓴다.
- 직접 성분 수치를 끝까지 찾지 못한 경우에도 식품원료 등재, 식용 부위, 생태·유통 특성, 조리 특성 중 독자 선택에 실제 도움이 되는 **확인된 식품학적 장점**을 조사한다.
- 단, 직접 영양 근거가 없는데 일반 새우의 단백질·EPA·DHA·미네랄 수치를 대상 종의 효능으로 바꾸지 않는다.

## 5. 저장 전 질문
1. 영양 DB 한 곳에서 못 찾았다는 이유로 조사를 멈추지 않았는가?
2. 학명·이명·해외명으로 확장 검색했는가?
3. 각 핵심 수치의 종·가식부·상태가 대상과 일치하는가?
4. 이름이 비슷한 다른 종의 자료를 섞지 않았는가?
5. `없다/확인되지 않았다`보다 독자에게 유용한 확인 정보가 먼저 제시됐는가?
6. 직접 근거와 참고 비교가 문장에서 구분되는가?
