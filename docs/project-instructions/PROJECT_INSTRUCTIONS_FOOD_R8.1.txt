## 2. 독자와 목적
- 이 블로그의 음식 글은 일반 독자가 음식을 이해하고 선택하고 먹고 보관하는 데 도움을 주는 생활형 건강·영양 콘텐츠다.
- 글의 출발점은 독자의 실제 질문이다.
- 작성 순서는 `독자 질문 → 벤치마크 → 생활정보 조사 → 유용한 정보 선별 → 사실 확인 → 일반 독자용 작성`으로 고정한다.
- 사실 확인 과정 자체를 본문 주제로 만들지 않는다.
- 음식에 실제로 포함된 고유 성분의 정량값과 확인된 연구상 작용은 본문에 살린다. 근거 없는 치료·예방 효과의 확정 주장만 제외하고, 성분 연구와 음식 섭취 효과를 구분해 독자에게 필요한 생활정보로 풀어 쓴다.
- 실제 안전사고·알레르기·독성·금기·위험한 오해를 막기 위해 꼭 필요한 내용은 명확하게 유지한다.

## 2-1. 기존 음식 글 재작성 원칙 — 원문 격리
- 사용자가 기존 음식 URL을 지정해 `수정`, `최신화`, `재작성`, `다시 작성`, `내용 점검 후 발행`을 요청하면 기본값은 **기존 본문 수정이 아니라 전면 신규 작성**이다.
- 기존 글에서 유지하는 것은 **숫자 URL·주제·카테고리·중복 방지에 필요한 식별 정보**뿐이다.
- 기존 본문의 문장·문단·표·강조·소제목 배치·출처 목록을 새 원고의 초안이나 재료로 사용하지 않는다.
- 기존 본문을 복사한 뒤 일부 문장만 바꾸거나, 문단을 이동하거나, 표만 교체하거나, 표현을 다듬는 방식으로 전체 재작성을 처리하지 않는다.
- 새 원고는 **빈 문서에서 시작**해 `검색 의도 확인 → 정확한 키워드 벤치마크 → 새 조사 → 사실 검증 → 정보 선별 → 6개 소제목에 새로 배치 → 강조·표·이미지 재선정` 순서로 만든다.
- 새 원고가 완성되기 전에는 기존 본문을 내용 소스로 사용하지 않는다. 새 원고 완성 후 누락 점검을 위해 기존 글을 대조할 수는 있지만, 기존 내용을 되살릴 때도 반드시 새 조사로 다시 확인한 뒤 새 문장으로 작성한다.
- 사용자가 `오탈자만`, `제목만`, `사진만`, `특정 문장만`, `표 하나만`처럼 수정 범위를 명확히 제한한 경우에만 부분 수정으로 처리한다.
- 범위가 명시되지 않은 기존 음식 글 작업은 항상 **원문 격리 + 전면 신규 작성**으로 처리한다.

## 3. 사용자 확정 음식 6개 소제목
음식 글의 핵심 소제목은 아래 6개로 고정한다. 사용자의 별도 지시 없이 이름·순서·의미를 임의 변경하지 않는다.

1. 소개
2. 영양소·핵심 성분
3. 꾸준 섭취 변화
4. 궁합·시너지
5. 주의사항
6. 고르는 법·보관법

- 다른 카테고리의 소제목 체계나 과거 공통 템플릿을 섞지 않는다.
- 내부 작업 용어와 검토용 분류를 독자용 H2로 사용하지 않는다.
- 각 H2 첫 문장은 일반 독자가 바로 이해할 수 있는 직접 답변이어야 한다.

## 4. 각 소제목의 역할
### 1) 소개
- 음식의 정체, 이름, 종류, 맛·식감, 제철·산지, 실제 유통 형태처럼 처음 보는 독자가 알아야 할 기본 정보를 다룬다.
- **제철 정보는 모든 음식 글의 소개에 반드시 포함한다.** 신규 글과 기존 글 전체 재작성 모두 예외 없이 적용한다.
- 제철을 작성하기 전에 **해당 음식의 제철을 다루는 다른 국내 음식 블로그를 최소 2개 이상 직접 확인**해, 독자들이 실제로 접하는 제철 월·계절·산지·품종 설명을 수집한다.
- 다른 블로그의 문장이나 주장을 복사하지 않는다. 블로그 조사는 제철 후보와 일반 독자의 표현 범위를 찾기 위한 벤치마크로만 사용한다.
- 블로그마다 제철 설명이 다르면 하나를 임의 선택하지 말고, 어종·품종·산지·자연산/양식·생물/냉동·수확 시기 차이를 추가 조사한다.
- 최종 제철 문장은 공공기관·수산/농업 전문기관·공식 생산지 자료·신뢰 가능한 전문자료 등으로 가능한 범위에서 교차확인한 뒤 작성한다.
- 참치처럼 한 음식명이 여러 어종을 포괄하면 `참치는 단일 제철로 묶기 어렵고, 참다랑어 등 어종·산지별 제철이 다르다`처럼 **대표 종류별 차이를 소개 안에서 설명**한다.
- 통조림·가공품·건조품처럼 자연 상태의 제철 개념이 약한 음식도 제철 항목을 생략하지 않는다. 원재료의 수확·어획 시기와 연중 유통 특성을 함께 설명해 `왜 제철 의미가 크거나 작지 않은지`를 소개에서 알려준다.

### 2) 영양소·핵심 성분
- 중요한 영양소와 핵심 성분을 설명하고 그것이 몸에서 어떤 역할을 하는지 쉬운 말로 연결한다.
- **모든 음식 글은 독자가 가장 먼저 확인하는 기본 영양정보를 생략하지 않는다.** 가능한 대표 기준량을 정해 최소 `열량(kcal)·탄수화물·단백질·지방`을 확인하고, 음식 특성상 중요한 경우 `당류·식이섬유·나트륨`도 함께 제시한다.
- 기본 영양정보를 먼저 제시하되 **진세노사이드·카테킨·폴리페놀·오메가3 같은 음식 고유 성분도 기본 영양과 함께 조사해 빠뜨리지 않는다.** 기본 영양표와 고유 성분의 설명은 서로 대체하지 않는다.
- 생것·말린 것·분말·농축액·통조림·음료처럼 형태에 따라 영양값 차이가 큰 음식은 **어떤 형태와 기준량의 값인지 제목이나 표에서 명확히 밝히고**, 독자가 실제로 자주 접하는 형태가 따로 있으면 짧게 비교한다.
- 가공식품·건강기능식품 성격이 강한 음식도 원재료 또는 대표 식품 형태의 기본 영양정보를 먼저 보여준 뒤, 제품별 진세노사이드·당류·나트륨·기능성 표시처럼 구매 판단 정보를 이어서 설명한다.
- 숫자 나열이나 일반 영양표만으로 소제목을 채우지 않는다. 기본 영양표 뒤에는 음식 고유 핵심성분과 몸에서의 역할, 형태별 차이를 서술형으로 연결한다.

### 3) 꾸준 섭취 변화
- **이 음식을 꾸준히 먹었을 때 몸에서 기대할 수 있는 긍정적인 변화를 중심으로 설명한다.** 생활 편의·조리 편의·보관 편의가 이 소제목의 중심이 되어서는 안 된다.
- 음식 특성에 맞게 체중 관리, 근육 유지·회복, 심혈관 건강, 뇌·인지 기능, 에너지 대사, 장 건강, 뼈 건강, 면역·피부 등 독자가 실제로 궁금해할 신체 변화를 폭넓게 확인해 필요한 항목을 고른다.
- 같은 성분을 반복 나열하지 말고 `무엇이 좋아질 수 있는지 → 왜 그런지 → 일상에서 어떻게 연결되는지` 순서로 쉽게 설명한다.
- **건강해지려는 독자의 꾸준한 실천 의욕을 뒷받침하는 글이어야 한다.** 확인된 유익 성분·기대 가능한 신체 변화·작게 시작할 수 있는 행동을 먼저 설명하고, 결과를 약속하지 않더라도 독자가 실천의 의미를 이해할 수 있도록 쓴다.
- **연구의 한계는 필요한 위치에서 짧고 정확하게 한 번 설명한다.** `효과가 없다/확인되지 않았다/케이퍼를 먹은 연구가 아니다` 같은 방어적 문장을 도입·성분·기대효과마다 반복하지 않는다. 성분·보충제·추출물 연구는 주체를 바로 밝혀 긍정적인 결과와 적용 범위를 함께 전달한다.
- 건강 변화의 가능성이 유망하다는 말과 사람에게 효과가 입증됐다는 말은 분리한다. 실제 결과가 없는 음식에 질병 예방·치료·혈당·면역 개선을 확정적으로 약속하지 않되, 검증 가능한 영양 기여·연구된 기전·긍정적 사람 연구는 축소하지 않는다.
- 자료 확인과 사실 검증은 내부 작업으로 처리하고, 독자용 본문에는 자료 유형·분석 방식·검증 단계를 나열하지 않는다.
- 독자가 원하는 것은 **몸에서 기대할 수 있는 변화와 실제 의미**다. 출처와 검증 과정은 본문 설명을 침범하지 않는다.
- 성분의 실측 함량·세포/동물 실험에서 관찰된 작용·사람 대상 연구 결과를 각 연구 수준대로 설명하고, 일반 음식 섭취에 입증되지 않은 치료 효과를 확정적으로 표현하는 것만 제외한다. 확인된 장점과 가능성 자체를 통째로 지우지 않는다.

### 4) 궁합·시너지
- 무엇과 같이 먹으면 좋은지, 왜 좋은지, 실제로 어떻게 먹을지 설명한다.
- 영양 보완·흡수 도움·맛과 식감의 조화를 구분해 과장 없이 설명한다.

### 5) 주의사항
- 알레르기, 과다섭취, 특정 질환·상황, 독성, 약물과의 중요한 상호작용 등 독자가 실제 행동을 바꿔야 하는 내용만 넣는다.
- 일반적인 부정·제한 설명으로 분량을 채우지 않는다.

### 6) 고르는 법·보관법
- 신선도, 구매 기준, 제품 형태 차이, 보관 위치·기간·방법, 손질·조리 시 실용 팁을 다룬다.
- **브랜드·완제품 비교가 실제 구매 판단에 도움이 되는 음식은 `추천 제품 TOP3`를 추가한다.** 판매량 순위를 그대로 복사하지 않고 핵심 성분·1일 섭취량·원재료·당류/불필요한 첨가·1일 비용·섭취 편의성·정보 투명성을 직접 비교한다.
- 추천은 `종합 균형형 / 고함량·성분형 / 가성비·편의형`처럼 서로 다른 독자 목적이 드러나게 구성하며, 같은 기준으로 1~3위를 억지로 세우지 않는다.
- **TOP3는 실제로 비교할 수 있는 후보가 충분하고, 공식 제품정보·건강기능식품 신고정보·제조사 정보·현재 판매정보 등으로 핵심 수치를 확인할 수 있을 때만 사용한다.** 확인이 부족하면 추천 순위를 만들지 않는다.
- 생선·채소·과일·원물처럼 브랜드 추천이 구매 판단에 큰 의미가 없는 음식에는 TOP3를 억지로 넣지 않는다.
- 가격은 변동 정보이므로 확인 시점의 판매가를 기준으로 `1일 비용`을 계산하고, 가격이 바뀔 수 있음을 짧게 밝힌다. 판매량·리뷰 수는 보조 참고만 하고 추천 근거의 중심으로 사용하지 않는다.
- 추천 제품에는 `왜 선정했는지`, `누구에게 잘 맞는지`, `아쉬운 점/비교 시 주의할 점`을 짧게 함께 적어 광고성 나열이 되지 않게 한다.

## 5. 조사와 벤치마크
- 먼저 일반 독자가 실제로 묻는 질문과 좋은 음식·건강 콘텐츠가 공통으로 다루는 정보 범위를 확인한다.
- 벤치마크는 문장이나 주장을 복사하기 위한 것이 아니라 빠진 질문과 실용 정보를 찾기 위한 절차다.
- **제철은 별도 필수 벤치마크 항목이다. 다른 국내 음식 블로그 최소 2개에서 제철 설명을 수집하지 않은 상태로 음식 원고 작성을 완료하지 않는다.**
- 제철 블로그 수집 시 `월/계절`, `품종·어종`, `산지`, `자연산·양식`, `생물·냉동/가공` 차이를 기록하고 상충 여부를 확인한다.
- 맛·식감·제철·산지·유통·먹는 법·제품 차이·보관처럼 생활에 필요한 정보를 폭넓게 조사한다.
- **영양 조사에서는 열량·탄수화물·단백질·지방을 기본 체크리스트로 먼저 확인한다.** 이후 음식 특성에 따라 당류·식이섬유·나트륨·비타민·무기질·고유 기능성 성분을 추가한다.
- 제품형 음식에서 TOP3가 유용하다면 공식 제품명·1일 섭취량·핵심 성분량·원재료/당류·구성 수량·현재 가격을 후보별로 같은 기준에서 조사한다. 단일 쇼핑몰 스니펫이나 판매량만으로 추천하지 않는다.
- 수치·영양·건강·안전 정보는 신뢰 가능한 자료로 사실 여부를 확인한다.
- 검색 스니펫·AI 요약만으로 수치나 건강정보를 확정하지 않는다.
- 사실 확인에 사용한 자료의 종류와 확인 과정은 독자에게 필요하지 않으면 본문에 설명하지 않는다.

## 6. 정보 밀도와 표
- 각 핵심 문단은 독자에게 새로운 사실·선택·행동 중 하나 이상을 제공해야 한다.
- 같은 내용을 도입·표·본문·요약에서 표현만 바꿔 반복하지 않는다.
- `100mL → 200mL`, `1개 → 2개` 같은 단순 배수·단위 환산으로 표를 늘리지 않는다.
- 표는 각 행·열이 서로 다른 선택 정보를 제공할 때만 사용한다.
- **② 영양소·핵심 성분에서는 기본 영양표와 고유 성분/기능성 표의 역할을 분리한다.** 기본 영양표를 빼고 기능성 표 하나로 대체하지 않는다.
- 추천 제품 표를 사용할 때는 `제품 / 핵심 성분 또는 함량 / 1일 비용 / 장점 / 주의점`처럼 실제 구매 비교에 필요한 열만 둔다. 판매량·마케팅 문구만으로 표를 채우지 않는다.
- 내용이 부족하면 표·강조·문장 수를 늘리지 말고 조사를 확장한다.

## 7. 긍정·실용 중심의 본문 균형
- 글의 첫인상과 대부분의 본문은 음식의 특징, 영양, 장점, 실제 활용, 선택, 섭취 행동을 중심으로 한다.
- **사실에 근거한 기대와 지속적인 작은 노력을 우선 전달한다.** 병을 치료한다는 약속 없이도 성분의 역할, 건강한 식사 패턴과의 연결, 실천 가능한 행동으로 독자에게 동기를 준다.
- 부정·제한·반박 문장이 글 전체를 지배하지 않게 한다.
- 안전상 반드시 필요한 주의는 5번 소제목에 집중하고, 다른 소제목에서 반복하지 않는다.
- 독자의 행동에 꼭 필요하지 않은 부정 설명은 본문에 추가하지 않는다.

## 8. 쉬운말
- 전문용어보다 일상적인 한국어를 우선한다.
- 기관명·DB명·전문 방법명·통계용어는 독자 판단에 필요하지 않으면 본문에서 빼고 출처에 둔다.
- 자료 유형·분석 방식·검증 등급을 설명하는 문장은 음식 본문에 쓰지 않는다. 독자용 본문은 결과·변화·선택·섭취 행동을 쉬운 말로 설명한다.
- 전문명이 필요하면 쉬운 설명을 먼저 쓰고 한 번만 보조한다.

## 9. 강조·이미지·내부링크
- 기존 direct/SP1 디자인과 3단계 강조 시스템을 사용한다.
- **강조 우선순위는 `본문에 반드시 있어야 하는가`가 아니라 `독자의 판단·행동·건강 이해를 실제로 바꾸는가`로 결정한다.** 필수 포함 항목이라는 이유만으로 상위 강조하지 않는다.
- 강조는 확인된 건강상 장점, 핵심 성분의 중요한 역할, 실제 섭취·선택·보관 행동, 꼭 필요한 안전 행동을 우선한다.
- **제철·산지·정의·명칭·분류·역사·배경 설명은 기본적으로 일반 문장으로 둔다.** 독자가 훑을 때 구분에 꼭 필요한 핵심 특징이면 굵게까지 허용하지만, 그 자체만으로 형광펜이나 밑줄을 사용하지 않는다.
- **제철 정보는 소개에 필수로 넣되, `필수 수집/필수 포함`과 `강조 가치`를 완전히 분리한다.** 제철이 실제 구매 시기·맛·품질·안전 판단을 크게 바꾸는 특수한 경우에만 해당 행동 결론을 강조할 수 있고, 조사 과정이나 `어종·산지별로 다르다` 같은 배경 설명은 상위 강조하지 않는다.
- **굵은 글씨는 3단계 중 가장 낮은 강조**다. 독자가 훑어볼 때 먼저 잡아야 할 긍정적 특징·장점·영양상 이점·좋은 궁합·맛과 활용상의 강점·실용적인 선택 및 섭취 팁에 사용할 수 있다.
- **형광펜은 굵은 글씨보다 높은 단계**이며, 독자가 기억하면 실제 선택이나 섭취 방식이 달라지는 핵심 이점·실천 행동에만 사용한다.
- **형광펜+밑줄은 최고 단계**이며, 글 전체에서 가장 중요한 건강상 결론, 가장 효과가 큰 실천 행동, 또는 놓치면 위해가 생길 수 있는 안전 행동에만 사용한다.
- 긍정적인 내용이라도 문단 전체를 굵게 만들지 말고, 핵심 단어·짧은 구절·핵심 결론만 골라 강조한다.
- 굵은 글씨·형광펜·밑줄의 개수를 목표로 맞추지 않는다. 강조 개수를 채우기 위해 낮은 가치 문장을 끌어올리지 않는다.
- 부정 문장·제한 문장·검토용 표현·출처 설명·조사 과정·정의 반복을 강조 개수 채우기용으로 사용하지 않는다.
- 저장 전 상위 강조 문장마다 `이 문장을 놓치면 독자의 건강 이해·선택·섭취·보관 행동이 달라지는가?`를 확인한다. 답이 아니면 형광펜/밑줄을 제거하고 일반 문장 또는 굵게로 낮춘다.
- 신규 및 전체 수정은 서로 다른 관련 본문 이미지 최소 3개를 사용한다.
- 내부링크는 실제로 관련된 기존 음식 글만 사용한다.

## 10. 저장 전 편집 검토
- 기존 글 전체 재작성이라면 기존 본문을 초안·문장 재료로 사용하지 않고 빈 문서에서 새 조사로 작성했는가?
- 사용자 확정 6개 소제목을 유지했는가?
- **소개에 제철 정보가 실제 문장으로 들어갔는가?**
- **제철 정보를 작성하기 전에 다른 국내 음식 블로그 최소 2개를 직접 확인했는가?**
- **블로그 간 제철 설명이 다를 경우 어종·품종·산지·유통 형태 차이를 교차확인했는가?**
- **② 영양소·핵심 성분에 기준량이 명확한 열량·탄수화물·단백질·지방 기본정보가 들어갔는가?**
- **가공·농축·건강기능식품형 음식에서 기능성 성분표가 기본 영양정보를 대신하고 있지 않은가?**
- **형태별 영양 차이가 크다면 어떤 형태의 수치인지 밝히고 대표 제품 형태 차이를 설명했는가?**
- **③ 꾸준 섭취 변화가 조리·보관 편의가 아니라 실제 긍정적 신체 변화를 중심으로 쓰였는가?**
- **③의 본문이 작성 과정 설명보다 독자가 기대할 변화와 실제 의미에 집중하는가?**
- **③의 각 문단이 긍정적 기대효과·꾸준한 실천 의미를 먼저 전달하고, 동일한 연구 한계를 여러 번 반복하지 않는가?**
- **⑥에서 브랜드 완제품 비교가 실제로 유용한 주제라면 최신 제품 후보를 같은 기준으로 비교해 TOP3를 검토했는가? 반대로 브랜드 추천이 무의미한 원물에 억지 TOP3를 넣지 않았는가?**
- **추천 TOP3가 판매량 순이 아니라 핵심성분·1일 비용·당류/첨가·섭취 편의성·정보 투명성 등 구매 판단 기준으로 설명되어 있는가?**
- **추천 수치·가격·제품명이 현재 확인 가능한 정보이며, 추천 이유와 아쉬운 점을 같이 적었는가?**
- **제철·산지·정의·명칭·분류·배경 설명을 단지 필수 정보라는 이유로 형광펜/밑줄 처리하지 않았는가?**
- **각 형광펜·밑줄 문장이 독자의 건강 이해·선택·섭취·보관 행동을 실제로 바꾸는 핵심 정보인가?**
- 일반 독자가 추가 검색 없이 핵심 내용을 이해할 만큼 정보가 충분한가?
- 장점·활용·선택·섭취·보관 정보가 충분한가?
- 사실 확인 과정이 독자용 본문을 차지하지 않는가?
- 핵심 성분의 실측 함량과 연구된 작용을 놓치지 않았고, 사람에게 확인된 섭취 효과와 구분해 독자에게 설명했는가?
- 같은 사실이나 단순 산술값을 반복하지 않았는가?
- 주의사항이 다른 소제목을 침범하지 않는가?
- 각 H2 첫 문장이 독자의 질문에 바로 답하는가?

## 11. 실행·완료
- 음식 원고 작성·수정은 direct/SP1 경로만 사용하며 Queue/Ollama 작성 경로를 사용하지 않는다.
- 신규: `posts/*.json` → `publish-posts.yml`
- 기존 수정: `updates/direct-*.json` → `direct-author-update.yml` → `update-posts.yml`
- 기존 수정의 기본 편집 방식은 부분 패치가 아니라 `2-1. 기존 음식 글 재작성 원칙`에 따른 전면 신규 작성이다.
- 실제 제출 시작 뒤에는 해당 source나 실행 코드를 임의 변경하지 않는다.
- HTTP 200, 제출 클릭, Actions SUCCESS만으로 완료라고 하지 않는다.
- source별 `PUBLIC_VERIFIED`와 신규 `published` 또는 기존 `updated` 원장을 확인한다.
- 불명확 제출 상태에서는 중복 재제출하지 않고 기존 source·원장·실행 상태부터 확인한다.

## 12. 도구·보안·변경 보호
- TinyFish, Browserbase 발행, Remote Desktop Commander 발행, Ollama 작성·강조 생성을 사용하지 않는다.
- 사용자에게 Node·CMD·gh·Chrome·GUI 조작을 요구하지 않는다.
- 비밀번호·OTP·CAPTCHA·쿠키·토큰·인증 헤더를 대화·원고·로그·Git에 노출하지 않는다.
- 승인 없는 삭제·URL 변경·권한 확대·유료 가입·스킨/광고 변경·force push·reset·비공개→공개 전환을 하지 않는다.
