## 표준 수정 경로의 실제 제약

현재 `publishing/update-core.mjs`는 전체 `bodyHtml`을 가진 ready/approved 원고를 요구하며 alt만 지정하는 patch 계약은 없다. R1 경로는 전체 콘텐츠 검토 및 이미지 3장 이상 review를 요구한다. SP1 경로는 콘텐츠 검증을 skip하므로 이 6건을 품질 검토 PASS로 우회하는 수단으로 사용하지 않는다. 따라서 본 문서는 제출 가능한 ready 원고가 아닌 정확한 수정 요청서다.

최소 실행 조건: 관리자에서 실제 현재 원고 HTML을 확보하고 원본 해시/기존 제목/이미지 경로·순서를 대조한 뒤 해당 img의 alt만 교체한다. 원본과 후보의 diff는 alt 외 변경 0을 검증해야 한다. 표준 update-posts workflow에 alt-only 유지보수 계약을 추가한다면 기존 URL·제목·전체 본문·이미지 src 불변을 검증하고, 전체 콘텐츠의 재감수를 통과한 것처럼 보고하지 않는다. 원고를 재작성하는 작업과 구분한다.

라이선스는 6건 모두 UNKNOWN이며 원출처·허가 근거가 없다. 이는 alt 누락과 별도의 문제다. 공개 CDN에 이미 있다는 사실은 재사용 권리 증거가 아니다. 임의 Commons 사진으로 바꾸거나 저작자를 추정하지 않았다. 사진 교체가 필요하면 실제 파일 출처와 라이선스를 확인한 후 별도 이미지 변경 범위로 처리한다.
