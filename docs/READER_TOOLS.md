# 공통 스킨 독서 기능

2026-10-09 nhunnhun 공통 스킨에 적용.

- 주요 제목(H2)만 표시하는 접이식 목차, 현재 읽는 항목 표시.
- 제목의 기존 ID를 유지하고 상단 여백을 고려해 이동.
- 키보드 포커스, 동작 줄이기 설정 지원.
- 직접 작성한 본문 사진은 클릭/Enter/Space로 확대, 닫기/Escape로 종료.
- 첫 본문 사진은 eager, 이후 사진은 lazy, 이미지 decoding은 async.

원고 발행 과정은 변경하지 않는다. 각 원고에 같은 스크립트를 붙이지 않고 공통 스킨을 사용한다. 새로운 목차/사진 라이브러리를 중복 설치하지 않는다.

배포 파일:

- `skin/proposals/reader-tools-20261009.js`
- `css/proposals/reader-tools-20261009.css`

스킨 변경 시 관리 화면의 최신 원본 HTML/CSS를 비공개 로컬 위치에 백업하고, 두 기존 AutoTOC/FloatingTOC 스크립트 블록을 제거한 뒤 새 스크립트와 CSS를 추가한다. 공개 저장소의 redacted reference는 배포 원본으로 사용하지 않는다. 코드 주석에 닫는 body/script 태그를 넣지 않는다. 티스토리 후처리가 이를 종료 태그로 해석할 수 있다.

검증: JavaScript 문법 검사, 공개 계란 글 목차 6개, 제목 이동 상단 약 100px, 사진 대화상자 열기/닫기, 390px 모바일 가로 넘침 없음. 이미지 압축과 서버측 검색은 이번에 추가하지 않았다.
