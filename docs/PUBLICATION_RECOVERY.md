# 신규 글 공개 검증 복구

제출 후 `submitting`이면 다시 발행하지 않는다. 관리자 목록에서 확인한 기존 숫자 URL을 사용한다.

`recover-publication.yml`을 main에서 source_id와 public_url로 실행한다. 이 경로는 익명 공개 브라우저만 열고 편집기·제출 API를 사용하지 않는다. 원장 fingerprint 일치, 제목 영역·OG, 본문 전체, 이미지 로딩·대표 이미지, 강조, PC·모바일을 기존 발행 검증과 같은 함수로 확인한다. 검증 성공 후 현재 원장 SHA가 변하지 않았을 때만 published로 전환한다. 실패하면 submitting을 유지한다.

제목은 NFC 정규화 후 공백·줄바꿈·제목 구분자(|,｜)를 제외하여 전체 일치를 확인한다. 다른 제목이나 잘못된 OG는 통과하지 않는다. 신규 발행은 발견한 URL을 공개 검사 전에 원장 checkpoint에 저장한다. URL 미발견·복수 URL·제목 불일치·OG 불일치를 별도 코드로 구분한다.

기술 검증 통과는 의미 검토나 발행 완료를 의미하지 않는다.
