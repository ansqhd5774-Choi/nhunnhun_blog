# 제목 최소 수정 후보 검토

공개 본문을 읽고 제목 약속을 실제 내용 범위로 축소했다. 실행 가능한 `updates` 원고가 아니라 검토용 후보 JSON이다. 본문·이미지·카테고리·대표 이미지·기타 메타를 변경할 승인이 필요한 새 내용으로 임의 재작성하지 않았다.

## /265 공식 근거 재확인

[EFSA 식품효소 안전성 평가](https://pmc.ncbi.nlm.nih.gov/articles/PMC9716715/)는 어린 염소·양·송아지의 제4위(abomasum)에서 얻은 키모신·펩신 A 렌넷을 우유 응고에 사용하는 것으로 설명한다. 본문의 ‘소, 새, 또는 양의 식도에서 추출’은 해당 동물성 렌넷 설명과 불일치한다. 렌넷 안전성 평가는 소화 개선·락토스 불내증 치료 효과 입증이 아니다.

본문에 렌넷 작용으로 대부분 락토스가 분해된다고 설명하는 문장은 근거 재작성 대상이다. 제목만 바꾸고 본문 효능 검증까지 완료로 보고하지 않는다. 이 문서는 새 의학 주장을 본문에 추가하지 않았다.

## 실제 변경과 한계

`docs/content-quality-title-minimal-candidates-20261010.json`에 현재 제목·제안 제목·관찰일·본문 텍스트 해시·보존 조건을 기록했다. 기존 /365 GitHub 원고는 존재하지만 contentStandard가 없으며, /129·/256·/265 게시 원고는 현재 origin/main에서 확인되지 않았다. 실제 보존 수정에는 관리자 HTML/메타 확보와 현재 계약에 맞는 최소 수정 경로 확인이 필요하다. HTTP 텍스트를 원본 HTML로 재구성하지 않았다. 원격 변경·발행·원장 변경 없음.
