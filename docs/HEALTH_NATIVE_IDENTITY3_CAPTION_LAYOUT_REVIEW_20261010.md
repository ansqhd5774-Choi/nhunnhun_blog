## 최소 교정 가능 범위

1. 확정 caption `/236 index0`은 native 매크로 JSON의 caption string 한 토큰만 변경하는 별도 조건이 필요하다. 현재 native-text-surgical-v1은 모든 매크로 byte 보존을 요구하므로 **현 계약으로는 변경 불가**. body hash·caption token hash·asset 대응·역복원을 요구하는 좁은 caption 동작을 추가해야 한다. 이미 구현된 alt JSON token parser 원리를 재사용할 수 있으나 허용 필드를 묵시적으로 넓히지 않는다.
2. 가독성은 새로 비워진 p/li와 전부 비어버린 목록 컨테이너만 정확한 HTML 범위 hash를 조건으로 제거하는 방식이 최소다. 원래 빈 p16개는 이번 교정 때문이 아니므로 그대로 둔다. style/link/image/macro가 포함된 요소를 제거해서는 안 된다. 현재 text-only 계약은 tag 삭제를 금지하므로 **현 계약으로는 정리 불가**.
3. 사진의 실제 주제가 잘못된 효능을 반복하는 경우 caption만 바꿔 문제를 덮지 않는다. 이때는 실제 픽셀 검토 후 비교 자료로 분명히 설명할지, 해당 사진을 제거할지 별도 판단한다. 이번 승인 범위가 이미지 보존이므로 현재 후보에서는 이미지 자체를 제거하지 않았다.

## 후속 로컬 교정

부모 승인으로 `/236 index0`의 정확 caption 토큰을 `티몰(Thymol)`로 바꾸고, 새로 빈 p/li 및 빈 목록 wrapper만 span으로 전환하는 좁은 계약을 추가했다. 자식 요소·모든 속성·inline style·원래 spacer p는 그대로 보존한다. `/236`80개 wrapper token, `/233`84개 wrapper token이다. 전체 488 회귀 PASS이며 실제 provider 원문과 예상 target 구조 대응도 PASS다.

**현재 판정:** 로컬 후보 교정은 완료했으며 원고는 모두 draft/approved:false. 실제 공개 제출·화면 가독성 검증 미실행. `/200`에는 caption/cleanup 추가 동작을 하지 않는다. 이전의 "현 계약으로 변경 불가"는 최초 text-only 계약의 제한이며 위 후속 조건이 해당 두 예외를 명시적으로 지원한다.
