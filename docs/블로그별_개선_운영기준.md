## 성과 판단

블로그별로 같은 기간의 검색 노출·클릭·CTR·순위와 광고 페이지뷰·RPM을 비교한다. 자동 검사 방문이 기존 통계 상승의 원인이었다고 단정하지 않는다. 노출이 있는 기존 글부터 검색 의도와 제목·본문·내부 링크를 개선한다. 건강 관련 주장과 수치는 공식 근거를 확인한다.

변경 후 검색 성과는 실제 데이터가 쌓인 뒤 판단한다. 코드 테스트와 실제 공개 화면 검사, 검색 성과 개선을 구분해 보고한다.
