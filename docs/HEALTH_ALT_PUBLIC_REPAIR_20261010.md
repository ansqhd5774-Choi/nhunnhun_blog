## 실패 원인과 교정

- 지연 로딩 사진을 노출하기 전에 전체 decode를 기다린 관찰 순서가 timeout을 유발했다. 순차 스크롤·로딩·디코드 검사로 교정한 실제 Run38013321883에서 사진6개 검사는565ms에 완료했다.
- 이후 provider 원문에 alt가 없는 사진에 기존 스킨이 data-filename을 입력해 byte 대조가 실패했다. 실제 이미지6개 src와 원자산은 모두 일치했다. 명시된 alt와 src 검사는 그대로 유지하고 확인된 파일명 보완만 검증했다.
- 초기 후보의 filename 추출 배선 누락은 메인 검토에서 발견해 병합 전에 수정했다. 실제 capture 함수의 DOM 추출 콜백을 실행하는 회귀를 추가했다. PR155 병합ce7b338, CI38013701558 PASS, 동일 후보400개 및 통합 관련32개 PASS.

## ImageGrid 후속 범위

/334는 Grid를 포함한 글의 일반 Image JSON에서 alt가 누락됐고, /342는 Grid attribute-list에서 alt가 누락됐다. 실제 원문과 공개 자산9/9·13/13의 유일 대응을 확인했다. 별도 엄격 parser가 기존 JSON과 Grid 그룹을 보존하고 해당 alt 토큰만 삽입한다. 자산 순서·해시·메타데이터·본문 조건 및 역복원 검사를 유지한다.

통합 관련40개·전체413개 회귀 PASS, 두 조건 원고 유지보수 계약 PASS. 실제 수정 결과는 후속 실행 후 추가하며 이 단계에서 두 글을 수정 완료로 처리하지 않는다.

### /334 제출 후 읽기 전용 대조

Run38014399423은 최종 제출 뒤 `E_ALT_PUBLIC_BODY_DRIFT`로 종료했고 원장은 `submitting`이다. 공개 페이지에 지정 alt가 표시되며 제목·이미지9개·자산·메타데이터·가로 넘침은 기존 조건과 일치했다. 원장 완료 전환이나 재제출은 하지 않았다. /342는 아직 실행하지 않았다.

저장된 편집기 native 본문을 읽기 전용으로 대조했다. macro 외 본문은 원본과 byte 단위로 동일했고, Image7개의 치수 값은 숫자에서 같은 값의 문자열로 직렬화됐다. Image7개와 Grid 안2개는 원자산을 유지하면서 서명 주소가 갱신됐으며 다른 JSON 필드와 Grid 속성 값은 동일했다. 이는 현재 확인한 저장 직렬화 차이이며 원고 내용 손실로 단정하지 않는다. 제출 전 provider 전체 본문 사본이 없어 공개 HTML에서 바뀐 정확한 속성은 아직 확인 불가다. 공개 본문 보존 검사 실패와 실제 내용 대조 결과를 구분해 유지한다.

기존 사진의 주제 관련성과 사용권은 별도 미완료다. 특히 /352의 소프트젤 사진과 /276의 라이코펜 제품 사진을 해당 글의 식품 또는 성분과 같다고 설명하지 않았다. 누락 alt 일부 수정만으로 운영24번 전체를 완료로 전환하지 않는다.
