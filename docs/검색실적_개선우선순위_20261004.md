## 다음 원고 작업 순서

1. /199 최신 공개 본문과 원본 백업, 제품 및 공식 식품 자료를 확인한다.
2. 제목과 첫 답변을 실제 검색 의도에 맞추고 기존 URL·카테고리를 유지한다.
3. 기존 표준 업데이트 원고와 workflow를 사용하고 대표 이미지·전체 본문·PC/모바일·발행 기록을 검증한다.
4. nutriments에는 같은 원고를 복제하지 않는다. 영양성분 설명은 해당 블로그의 기존 글과 중복 여부를 별도로 확인한다.
5. 수정일 이후의 동일 기간 검색 실적을 비교한다. 순위·수익 상승을 사전에 보장하지 않는다.

이 문서는 작업 우선순위이며 실제 원고 수정·공개 완료 기록이 아니다.
