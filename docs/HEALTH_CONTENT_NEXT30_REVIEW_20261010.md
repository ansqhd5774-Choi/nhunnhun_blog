# 추가 30개 본문 의미 검토 — 2026-10-10

범위: 기존 356개 공개 글 checkpoint에서 앞선 후보 30개를 제외한 다음 30개를 새로 조회했다. 모든 HTTP 응답은 200이며 본문 총 180,361자다. HTTP 성공이나 자동 키워드 검색을 의미 감수 PASS로 처리하지 않았다. 새 수정/발행은 실행하지 않았다.

## 확정 오류

- `/411`: 출처의 **부피비** `테프 1컵 : 물 3컵`을 표에서 **질량·부피** `건조 테프 40g + 물 약120mL`로 전환했다. 이 환산을 뒷받침하는 원료 밀도나 실제 제품 조리 안내가 없다. 섭취 중량 계산과 조리 부피비를 분리해야 한다.
- 확인 원문: [Colorado State University Teff](https://foodsmartcolorado.colostate.edu/food/foods-and-beverages/teff/), [WGC Cooking Whole Grains](https://wholegrainscouncil.org/recipes/cooking-whole-grains). 양쪽 모두 테프 한 컵에 물 세 컵을 안내한다.
- 최소 수정 조건: 동일 계량컵으로 부피 1:3이라고 명시하고 약20분/농도·제품 안내 조건을 유지한다. `40g→120mL`를 본문·표·FAQ에서 일괄 제거한다. 건조40g 영양표의 단순 환산 자체는 이 오류와 별개다.
