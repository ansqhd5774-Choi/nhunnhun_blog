# 후속 작업 실제 반영과 남은 검증

## 공개 반영 완료

- `/381`: 국내 제철과 미국 농장 사례를 구분한 본문 공개 반영. 최초 실행 `38015922026`은 실제 수정 후 SP1 강조 검사 불일치로 실패했다. SP1 원래 렌더 계약을 검사하도록 수정한 뒤 읽기 전용 실행 `38016432443`에서 PUBLIC_VERIFIED/updated. 재제출하지 않았다.
- `/405`: USDA 영양값 표시 정밀도 7곳 교정. 실행 `38016457932`에서 PUBLIC_VERIFIED/updated. 직접 작성 렌더와 사진·강조를 보존하는 원고를 사용했다. 별도 수동 실행 `38016440162`는 작업 시작 전에 취소됐고 제출하지 않았다.
- 두 원장의 source ID·파일 SHA·fingerprint·실행 URL·공개 검증 시각을 준비된 전체 출처 검토와 대조했다. private supersession 원장에만 연결했고 과거 확인일 null을 소급 변경하지 않았다. 과거 미확인 145건 중 대체 완료 7건, 남은 대상 138건.

PC 1440/모바일 390에서 두 글 모두 사진 3장 로딩과 가로 넘침 0px를 확인한 러너 증거가 있다. `/405` 공개 본문의 19.9·17.3도 직접 조회했다. `/381`에는 원래 제목의 숫자와 SP1 자동 번호가 겹치는 소제목 표시가 관찰돼 추가 수정 대상으로 남긴다.

## 기존 성분명 교정 준비

`/236`, `/233`, `/200` 전용 native-text-surgical-v1 경로를 준비했다. 원문 전체 hash, 메타정보, 텍스트 노드, 이미지 자산, 공개 본문과 구조가 일치해야 실행할 수 있다. HTML 모드 전환 직후 원문을 다시 읽어 입력 전에 검사한다. 최종 제출은 한 번이며 실패 후 읽기 전용 검증으로 복구한다.

조건 원고는 `docs/candidates/`에 draft/approved:false로 보관한다. 자동 제출 대상 updates에 넣지 않았다. 실제 HTML 모드 원문 대응과 후보 가독성이 아직 검증되지 않았으므로 공개 수정 완료로 보고하지 않는다. 로컬 파일 미리보기는 브라우저 URL 정책으로 차단됐으며 다른 경로로 우회하지 않았다. 구현 통합 회귀검사 446/446 PASS는 Production 증거가 아니다.

## 전체 미완료 범위

32개 운영 항목은 완료22/미완료9/보류1을 유지한다. 미완료는 근거 추적·날짜·재검토·글별 색인·IndexNow·검색 제목/설명·이미지 품질·모바일 성능/접근성·성과별 개선이다. 홍보는 사용자 지정 채널 없음으로 보류한다.

- 근거/날짜: 남은 138건의 실제 주장 대조 필요. `/91` 일부 영양·보관 출처는 확인했지만 인체시험·알레르기 등의 근거가 남아 전체 확인일을 채우지 않았다.
- 제목/내용: 세 성분명 교정은 후보 단계다.
- 이미지: `/334` 공개 alt 변경과 native 보존 증거는 있으나 전체 provider 보존 확인이 끝나지 않아 submitting을 임의 복구하거나 재제출하지 않았다. `/342`도 미실행.
- 비공개 `/397`: 공개 전환 승인이 없어 상태를 변경하지 않는다.
- 성능: 최신 PSI CLS 0.411/LCP 7.4s 문제가 남는다. 화면을 숨기거나 광고를 삭제하는 우회는 적용하지 않았다.
- 색인/성과: 검색엔진 처리 및 수정 후 비교 기간은 미확정. 대기 상태를 발행 실패로 처리하지 않는다. Tistory 동일 호스트의 IndexNow 키 제공 경로도 확보되지 않았다.

전체 완료 판정은 아직 불가하다. 세 교정 후보의 엄격한 원문 대응과 공개 검증, 미확인 출처의 bounded 검토를 이어가며 외부 처리 대기와 실제 오류를 구분한다.

## 소제목 번호 후속 완료

PR160에서 SP1 원고의 기존 번호 보존을 적용했다. `/381` 표준 수정 Run `38017173387` SUCCESS, PUBLIC_VERIFIED/updated 및 PC/모바일 넘침0·사진3장 확인. 실제 공개 H2 16개의 번호가 한 번씩 표시되는 것을 직접 확인했다. 제목·본문의 정보와 이미지·강조는 그대로 유지했다. 위 중복 번호 관찰은 당시 문제 이력이며 현재는 해결됐다.

읽기 전용 native preflight는 기존 observe-alt-maintenance workflow에 선택 scope만 추가했다. raw 본문·메타정보·서명 URL 대신 안전한 hash와 단계 결과만 보존한다. 통합 회귀 458/458 PASS이며 실제 preflight 결과는 별도 확인한다.
