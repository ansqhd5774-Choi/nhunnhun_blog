# 미완료 10개 병행 작업

대상은 한입 건강이다. 시작 원격 main `8fc25a9`. 이전 21개 완료 범위와 홍보 채널 없음 보류를 유지한다. 후보를 만드는 코드, 실제 본문 검토, 공개 수정, 제공자 색인 결과는 별도 판정한다.

## 검색 관리 직접 확인

2026-10-10 Bing 공식 URL Inspection의 `/282`는 `Indexed successfully`였다. 메타 설명 길이와 canonical 두 개 관찰은 SEO 경고이며 실제 색인을 취소하지 않는다. Site Explorer는 `No data available`, Search Performance는 48시간 후 재확인 안내였다. 이를 전체 미색인이나 유입 0으로 기록하지 않는다. 이전 사이트맵 재제출을 반복하지 않았다.

IndexNow의 [공식 규격](https://www.indexnow.org/documentation)은 제출 호스트 내 UTF-8 키 파일을 요구한다. [Tistory 공식 파일 구조](https://tistory.github.io/document-tistory-skin/common/files.html)는 추가 파일을 스킨 images 아래에 둔다. 현재 확인한 기능으로 숫자 글의 원래 호스트 루트에 키 파일을 제공하는 경로가 확보되지 않았다. 14번은 제공 경로 미확인/후순위이며 허위 keyLocation이나 다른 호스트로 제출하지 않는다. 사이트맵과 공식 URL 검사 경로는 유지한다.

## 실제 스킨 보완

관리자 최신 HTML을 별도 백업하고 원본 일치를 대조한 뒤 목차 문구 초기화 한 곳만 수정했다. 이전에는 긴 제목을 생성한 후 다른 스크립트가 `｜` 앞부분으로 줄였다. 처음부터 최종 짧은 제목을 생성하고 전체 제목은 title과 dataset에 보존하도록 했다. 공식 편집기 입력을 다시 읽어 줄바꿈 정규화 후 완전 일치를 확인하고 적용을 한 번 실행했다.

공개 `/282`에서 수정 스크립트, 목차9개·전체 제목 속성·목적지9개 존재를 확인했다. PC와 모바일390px 가로 넘침0px. 목차 삽입 자체의 지연은 이 변경으로 해결했다고 주장하지 않는다. 새 성능 측정은 별도 후속 기록을 따른다. 원본 전체·식별자를 저장소에 넣지 않고 재현 가능한 패치 도구와 독립5검사만 저장한다.

최신 main `952db0b`로 동기화한 통합 로컬 회귀324개가 통과했다. `/268` 성분·과장 표현과 `/388` 최신 국내 허가·FDA 경고는 실제 수정 원고 준비 중이며 현재 공개 수정 완료로 보고하지 않는다.

## 판정 원칙

외부 제공자 처리 대기와 IndexNow 경로 미확인은 해당 항목만 제한한다. 근거·날짜·이미지의 미확인 기록은 실제 원문/시각 검토로 해소해야 하며 자동 목록 생성만으로 완료하지 않는다. 새 성능 측정의 실패도 숨기지 않는다. 10개 전체 완료로 보고하지 않는다.
