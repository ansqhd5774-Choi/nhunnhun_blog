# 출처 확인일 원장 보완

기존 재검토 목록 도구가 모든 sourceCheckedAt을 null로 만들던 동작을 보완했다. 현재 원고와 contentDigest가 일치하고 승인된 R1 검토서에 연결된 본문 근거의 실제 checkedAt만 재사용한다. 검토일보다 늦은 확인일·미래일·존재하지 않는 날짜·본문에 없는 근거·stale 검토서는 채택하지 않는다.

기존 운영 계약의 안전/허가/지침30일, 일반 정보90일, 영양 기준365일에 따라 근거별 다음 검토일을 기록한다. 원고의 요약 확인일과 다음 검토일은 가장 이른 해당 일자다. 이것은 기록에서 계산한 운영 일정이며 새 조사·독립 의료 감수·현재 근거가 유효하다는 인증이 아니다. 발행일과 분리하고 발행 게이트에 추가하지 않는다.

현재 원고132개를 실제 읽은 결과, 일치하는 확인일 기록이 있는 원고3개, 미확인129개다. 기술 공개검증 기록22개와 확인일3개는 다른 집계다. 이 원고 목록은 공개 글356개 전체를 대표하지 않는다. direct 경로에 R1 검토서를 소급 강제하거나 날짜를 만들어 넣지 않았다.

출력 원장은 private evidence/health-growth-final-20261010/runtime-quality/review-dates-final에 저장했다. 과거 개정일 전체 대조와 미확인 근거 실제 확인은 계속 미완료다. 이 개선으로 날짜 관리 항목을 전체 완료로 바꾸지 않는다.
