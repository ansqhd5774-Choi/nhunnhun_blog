# 공통 Producer 적용 정책

음식·영양소·약·질병은 같은 Queue/작성/검토/기존 수정 workflow를 사용한다. 주제 전용 러너를 추가하지 않는다.

- 공통 필수: 주제와 실제 대상 일치, 읽은 출처와 본문 연결, 근거 없는 수치·효능 금지, 안전정보, 기존 R1/R4 HTML·이미지·검토 계약, source SHA·mutex·원장·중복 제출 방지.
- 분야 core: 해당 분야의 기본 질문을 실제로 답한다. 근거가 확인되지 않은 수치·효과는 확인 자료의 범위와 한계를 설명할 수 있다. 세계 전체 근거 부재로 단정하지 않는다. 허가사항·필수 의료 안전정보를 확인하지 못한 경우에는 제출하지 않는다.
- 확장: 프로필은 검토 후보이며 강제가 아니다. 현재 독자 질문과 확인 근거에 따라 applies/reason을 결정한다. 제외된 확장은 필수 모듈을 늘리지 않는다. 포함된 확장은 실제 답변과 출처 검사를 유지한다.
- 일반 자료: 적용되는 일반 생활 안내로 사용 가능하다. 일반 식단·농업 연구를 개별 식품의 치료·예방·권장량 증거로 쓰지 않는다. 주제 단어 일치는 검색 보조 신호이며 주장과 출처의 일치 증명이 아니다.
- 문체: 섹션별 비교·추가 행동은 선택이다. 형식을 채우기 위한 주장·반복을 만들지 않는다. 강조·위험 안내의 기존 규격은 유지한다.
- 조기 검사: 조립 직후 HTML/이미지/source/렌더 계약을 검사하고 assembled 기록을 남긴다. 이후 AI 검토, 최종 R1/R4 검사를 통과해야 READY_FOR_UPDATE로 승격한다.
- 경고: 추천 프로필 제외와 편집 경고는 실제 판단을 기록한다. 필수 안전·정체·근거 오류를 경고 해소로 우회하지 않는다.

Ollama 자체 검토는 ai/same-author다. 코드 PASS는 계약 검사이며 의학적 정확성의 독립 증명이 아니다. 이 정책 변경은 기존 글 재작성·실제 제출·Queue BLOCKED 해제를 자동 실행하지 않는다.
