# R5.5 단일 작성 자동 수정

## 음식 취합·강조·대표 사진 개선

음식 소개는 본문에서 한 번만 출력한다. 번호 목록은 Markdown 변환에서 별도 항목으로 처리한다. 수집된 자료의 notes를 여섯 작성 요청에 전달하며 각 항목에 관련된 정보를 사용하도록 안내한다. 완성 원고의 여섯 항목에서 Ollama가 중요 문구와 중요도만 한 번 선택하며 원문에 존재하는 구절에 코드가 1단계 굵게, 2단계 굵게+형광펜, 3단계 굵게+형광펜+밑줄을 누적 적용한다. 의미 검토·재작성 반복은 추가하지 않는다. 강조 선택 시간은 emphasisMs로 별도 기록한다.

모든 항목은 지정 검색어나 주제명으로 사진을 검색한다. 최초 확보 이미지 한 장은 대표 사진이며 기존 수정 러너의 대표 이미지 업로드에 연결된다. 이미지가 없으면 주제명 검색과 확대 후보로 한 번 재시도한다. 이후에도 없으면 E_IMAGE_REPRESENTATIVE_REQUIRED로 발행 전에 중단한다. 이미지 예외는 단계 오류 코드와 HTTP 상태를 기록한다. 사진 선택 결과는 사실 검증을 뜻하지 않는다.

## 실행 대기 단축 (2026-10-08)

수동 article_id 지정은 과거 원고 BLOCKED 상태를 재개한다. 자동 순회는 과거 차단 항목을 계속 건너뛰며, 제출 불명확·실행 중·시스템 오류·발행 대기 보호는 수동 지정에도 유지한다. 코드 변경 push는 실제 글 생성을 시작하지 않는다. 작업 목록 변경 push, 수동 실행, 기존 예약 실행은 유지한다. 취소된 실행과 produce가 생략된 실행은 summary 러너를 배정하지 않는다. summary는 Node 내장 모듈만 사용하므로 pnpm 준비·의존성 설치를 생략한다.

갈치 실행 37778953422 실측: writer 42.639초, 이미지 9.957초, 생성 전체 56.990초. 기존 글 수정 실행 37779457788에서 2026-10-08 21:50:49 KST 최종 제출 클릭을 기록했다. 최초 요청 실행은 과거 BLOCKED_CONTENT를 건너뛰어 글을 생성하지 않았다. 위 대기 단축 변경의 적용 후 전체 시간은 아직 재측정하지 않았다.

## Ollama 원고 검사 제거 (2026-10-08)

SP1 자동 원고에는 내용·효능·근거·길이·섹션 수·강조·표·요약·출처 배치에 대한 Editorial/Content 검사를 실행하지 않는다. Producer는 생성 원고를 취합하며 dry-run 결과는 DRY_RUN_GENERATED로 기록한다. CONTENT_VALIDATION_SKIPPED는 검사 PASS가 아니다. 생성 응답 수신/JSON 읽기, 빈 원고, 대상 URL/승인/해시·source drift/중복 제출/HTML 보안/이미지 라이선스와 발행 결과 확인은 실행·보안 보호로 유지한다. 기존 수동 R1 원고에는 이 예외를 확대하지 않는다. Queue의 코드 테스트는 PR에서만 실행하며 실제 생성 작업의 선행 조건으로 두지 않는다.

대상 URL/제목, 승인, source drift, 중복·불확실 제출, 이미지 기존 검토 기록, HTML 안전성, 원장·공개 검증은 유지한다. 기술 실패는 ERROR_SYSTEM으로 저장 후 종료하며 내용 오류의 자동 반복 재시도는 없다. 과거 BLOCKED도 자동 재시도하지 않는다.

## 음식 작성 후 디자인 처리

Ollama의 음식 요청에는 주제·제목·언어·형식·내용만 전달한다. 굵은 글씨·형광펜을 작성 모델의 필수 작업으로 요구하지 않는다. 취합 후 food-design.mjs가 기존 문장과 기존 강조를 유지하면서 번호 문단을 실제 목록으로 변환하고, 항목명과 수치를 굵게 표시한다. 각 항목의 짧은 주의/실행 문구에 제한적으로 형광펜을 적용하며 일반 효능 문장을 자동 강조하지 않는다. 모든 키워드에 일괄 형광펜을 적용하지 않는다. 의미를 자유롭게 판정하는 AI 검토가 아니라 정해진 디자인 규칙이며 추가 AI 호출·내용 검사·원고 재작성은 없다. SP1 렌더러가 문단·목록 간격과 모바일 표 줄바꿈을 적용한다.

## SP1 이미지 선택과 배치

이미지 선택 기준은 검색어·관련성·선택 판단·사용 개수·중복·설명/대체텍스트의 6개다. 제외 대상 목록·출처/권한 필수 조건·검색 실패 시 기존 사진을 넣는 규칙은 삭제한다. 기존 원고의 6개 항목을 취합한 뒤 동일 Actions 실행 안에서 Ollama가 실제 내용에 맞는 사진 검색어를 만들고, Commons 후보 사진을 첨부한 시각 요청으로 항목별 적합성을 판단한다. 항목당 0~1개, 원본 파일과 비슷한 구도의 반복 사진은 사용하지 않는다. 설명 가치가 없으면 생략한다. 대체텍스트는 사진에 실제 보이는 내용을 사용한다. 제공되는 메타데이터는 기록하되 선택을 막는 조건으로 쓰지 않는다. 기존 대표이미지 설정은 변경하지 않는다. SP1 이미지 표시 크기 제한과 유동 폭 표는 유지한다. 원고 재작성·내용 검토·공개 확인을 추가하지 않는다.
