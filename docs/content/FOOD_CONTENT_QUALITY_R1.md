# 음식 콘텐츠 품질 기준 R1

적용 범위: `category=음식` 신규 글과 기존 글 전체 재작성

이 문서는 음식 글의 **정보 깊이·벤치마크·정보 밀도·표·반복 제거·독자 만족도**를 규정한다. 음식의 기본 6축과 사실 정확성 기준은 `docs/project-instructions/PROJECT_INSTRUCTIONS_FOOD_R8.1.txt`를 따른다. 이 문서는 그 기준을 대체하지 않고, 글이 형식적으로만 PASS하는 것을 막는 품질 보강 기준이다.

## 1. 최우선 목표

- 목표는 6개 H2를 채우는 것이 아니라 **검색한 독자가 추가 검색 없이 핵심 판단을 할 수 있을 만큼 유용한 정보를 제공하는 것**이다.
- 6축·표·강조·이미지는 정보 전달 도구다. 이것들의 개수를 채웠다는 이유로 콘텐츠 품질이 충족된 것으로 보지 않는다.
- 정확한 정보라도 독자에게 새 판단을 주지 못하는 반복·산술 확장·상식 수준의 문장은 분량으로 계산하지 않는다.
- 내용이 얕으면 문장·표·강조를 늘리지 말고 **조사를 확장**한다.

## 2. 작성 전 벤치마크

### 2.1 언제 필수인가
다음 작업은 작성 전에 벤치마크를 수행한다.

- 신규 음식 글
- 기존 음식 글의 전체 재작성
- 검색 의도가 넓은 대표 식품(예: 우유, 달걀, 연어, 오트밀 등)
- 작성자가 어떤 정보를 더 넣어야 할지 판단하기 어려운 주제
- 조사 후에도 정보량이 부족하거나 일반론만 남는 주제

### 2.2 벤치마크 목적
벤치마크는 문장·수치·구조를 복사하기 위한 것이 아니다. 다음만 파악한다.

- 독자가 반복해서 묻는 핵심 질문
- 우수 콘텐츠가 공통으로 다루는 정보 범위
- 실제 구매·섭취·보관 선택에 도움이 되는 비교 항목
- 기존 원고가 빠뜨린 질문
- 우리 글에서 더 명확히 답할 수 있는 부분

### 2.3 벤치마크 대상
가능하면 3~5개를 본다.

1. 대학·병원·공공기관의 건강·영양 콘텐츠
2. 전문 건강·영양 미디어
3. 식품·영양 분야의 신뢰도 높은 전문 콘텐츠
4. 정확한 동일 주제가 부족하면 같은 식품군의 우수 콘텐츠

개인 블로그·커뮤니티는 질문 발견용으로만 참고할 수 있으며, 핵심 사실의 근거로 그대로 사용하지 않는다.

### 2.4 사실 검증 분리
- 벤치마크에서 발견한 효능·수치·권장량·안전 정보는 공식 DB·정부·전문기관·원문 연구로 별도 검증한다.
- 벤치마크 사이트가 다루고 있다는 이유만으로 사실로 확정하지 않는다.

## 3. 독자 질문 지도

작성 전에 내부적으로 다음 세 층을 정리한다.

### A. 핵심 이해
- 이 음식은 무엇인가?
- 다른 비슷한 식품과 무엇이 다른가?
- 이 음식을 특징짓는 성분·맛·식감·가공 형태는 무엇인가?

### B. 건강·선택
- 어떤 건강상 장점이 실제로 확인되는가?
- 누구에게 특히 유용한가?
- 일반형·저지방·무가당·락토프리·생/말린 등 선택지가 있다면 무엇이 다른가?

### C. 행동
- 얼마를 어떻게 먹는가?
- 무엇과 먹으면 좋은가?
- 누가 주의해야 하는가?
- 무엇을 보고 고르고 어떻게 보관하는가?

이 질문들을 음식 6축에 재배치한다. **6축을 먼저 만들고 내용을 억지로 끼워 넣지 않는다.**

## 4. 정보 밀도

### 4.1 새 정보 원칙
- 핵심 문단 하나는 최소 하나의 새로운 판단 정보를 제공해야 한다.
- 같은 사실을 도입·표·본문·요약에서 표현만 바꿔 반복하지 않는다.
- 중요한 핵심은 요약에서 한 번 재제시할 수 있지만, 반복 자체를 정보량으로 보지 않는다.

### 4.2 산술 반복 금지
다음은 원칙적으로 저가치 반복이다.

- 100mL 값을 200mL로 단순 2배 계산해 표의 별도 열로 확장
- 1개 값을 2개·3개 기준으로 단순 곱해 여러 행으로 확장
- 같은 영양값을 g·mg·%로 불필요하게 반복
- 본문에 있는 수치를 표에 그대로 복제하면서 비교 의미가 없는 경우

기준량이 여러 개 필요한 경우는 **그 차이가 실제 선택이나 섭취 판단을 바꿀 때만** 허용한다.

예: 100g과 1회 제공량의 비교가 실제 섭취 판단에 필요하거나, 생것과 조리 후 값이 달라 비교 가치가 있는 경우.

### 4.3 기준량 선택
- 독자가 실제로 먹는 양이 명확한 식품은 **실사용 1회량**을 우선한다.
- 영양 DB의 100g/100mL 값은 근거 확인에 사용하되, 독자용 표에서 반드시 병기할 필요는 없다.
- 기준량 두 개를 함께 보여줄 때는 각각이 다른 질문에 답해야 한다.

## 5. 표 작성 기준

표는 **비교가 읽기보다 빠를 때만** 사용한다.

### 좋은 표
- 일반 우유 vs 저지방 vs 무지방 vs 락토프리
- 생연어 vs 훈제연어의 나트륨·용도 차이
- 신선한 상태 vs 상한 상태의 고르는 기준
- 품종·가공형태별 실제 선택 차이

### 나쁜 표
- 100mL와 200mL 단순 배수
- 같은 내용을 문장과 표로 중복
- 숫자가 있다는 이유만으로 만든 영양표
- 열과 행 대부분이 독자의 선택을 바꾸지 않는 표

표를 넣기 전에 다음을 확인한다.

1. 각 열은 서로 다른 질문에 답하는가?
2. 각 행은 독자에게 새로운 판단을 주는가?
3. 표가 없으면 이해가 더 어려워지는가?
4. 단순 계산이나 단위 환산으로 칸을 채우고 있지 않은가?

하나라도 명확한 이유가 없으면 표 대신 문장·목록으로 쓴다.

## 6. 음식 고유 정보 우선

- ① 정의·주요 성분·작용은 일반 열량·단백질·지방 표를 넣는 자리가 아니다.
- 독자가 그 음식을 다른 식품과 구분할 수 있는 특징을 먼저 설명한다.
- 대표 성분, 식품 구조, 가공 형태, 맛·식감, 품종·종 차이, 실제 유통 형태 등이 중요한 음식은 이를 먼저 다룬다.
- 일반 영양 수치는 필요한 핵심만 사용하고, 음식 고유 특징보다 더 많은 공간을 차지하지 않게 한다.

## 7. 선택 가치와 행동 가치

좋은 음식 글은 다음 중 적어도 여러 항목에 직접 답해야 한다.

- 어떤 제품·형태를 고를 것인가?
- 어떤 사람에게 더 적합한가?
- 어떤 경우 다른 형태를 고르는 것이 좋은가?
- 언제·어떻게 먹으면 편한가?
- 어떤 음식과 조합하면 영양 구성이 좋아지는가?
- 어떤 증상·상황에서는 피하거나 바꿔야 하는가?
- 신선한 제품을 어떻게 구분하는가?

단순히 `좋다`, `영양이 풍부하다`, `균형 잡힌 식단에 도움이 된다`로 끝내지 않는다.

## 8. 효능 작성 품질

- 효능은 성분 이름 나열이 아니라 **몸에서 하는 역할 → 이 음식으로 얻는 실제 의미 → 독자의 활용** 순서로 설명한다.
- 질병 예방·치료 효과를 과장하지 않는다.
- 근거가 제한적이면 짧게 범위를 설명하되, 한계 설명이 본문 중심이 되지 않게 한다.
- 확인된 장점이 적은 음식은 없는 효능을 만들지 말고 맛·식사 활용·선택·보관 등 실제 가치가 높은 정보를 더 조사한다.

## 9. 벤치마크 후 조사 확장 기준

다음 중 하나라도 해당하면 초안을 쓰기 전에 조사를 더 한다.

- 벤치마크에서 반복되는 핵심 질문에 답할 자료가 없음
- 6축 중 두 개 이상이 일반론 한두 문장으로 끝남
- 동일 수치나 동일 효능을 여러 문단에서 반복해야 분량이 나옴
- 표를 단순 산술값으로 채워야 할 정도로 비교 정보가 없음
- 선택·섭취·보관에서 독자가 실제로 할 행동을 제시하기 어려움

## 10. 강조 품질

- 강조는 정보의 중요도를 보여주는 도구다.
- 단순 계산값·반복 수치·문단 채우기용 문장은 강조하지 않는다.
- 최고강조 우선순위는 다음과 같다.
  1. 확인된 핵심 건강상 장점
  2. 독자의 판단을 바꾸는 핵심 수치
  3. 제품·식품 선택 기준
  4. 실제 섭취·보관 행동
  5. 놓치면 위험한 안전 행동
- 강조 하한을 맞추기 위해 정보 가치가 낮은 문장을 끌어올리지 않는다.

## 11. 통합 품질 검토

저장 전 다음을 사람이 의미 기준으로 검토한다. 자동 의미 PASS로 대체하지 않는다.

- 이 글을 읽고 독자가 추가 검색해야 할 핵심 질문이 남아 있는가?
- 6축 각각이 서로 다른 정보를 제공하는가?
- 같은 사실을 수치·표현만 바꿔 반복하지 않았는가?
- 표의 각 행·열이 새로운 판단 정보를 주는가?
- 일반 영양표가 음식 고유 특징을 밀어내지 않았는가?
- 벤치마크에서 확인한 중요한 독자 질문을 빠뜨리지 않았는가?
- 내용이 부족한 부분을 조사 확장 대신 문장·표·강조로 채우지 않았는가?
- 구매·섭취·조합·주의·보관 중 독자가 실제 행동으로 옮길 정보가 충분한가?

## 12. 금지 패턴

다음 패턴은 콘텐츠 품질 실패로 본다.

- `100mL → 200mL` 같은 단순 배수 표로 정보량을 늘림
- 똑같은 영양소 수치를 도입·표·본문·요약에 반복
- 자료가 부족한데 `공식 권장량이 없다`, `연구가 부족하다`는 설명만 길게 작성
- 모든 음식에 같은 일반론을 복사하듯 적용
- 식품 선택에 도움되지 않는 표·목록을 형식상 삽입
- 벤치마크 없이 낮은 정보량의 초안을 바로 발행
- 정확하지만 독자의 실제 질문에 답하지 않는 DB 나열형 글

## 13. 작성 순서

표준 콘텐츠 작성 순서는 다음과 같다.

`검색 의도 확인 → 기존 글·중복 확인 → 벤치마크 → 독자 질문 지도 → 폭넓은 조사 → 사실 검증 → 정보 선별 → 음식 6축 재구성 → 본문 작성 → 정보 밀도·표·반복 검토 → 강조·이미지·내부링크 → 통합 품질 검토 → Gate 0 → 저장·발행`

기술 preflight와 PUBLIC_VERIFIED는 이 콘텐츠 품질 검토를 대신하지 않는다.
