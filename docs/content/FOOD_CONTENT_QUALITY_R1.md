# 음식 콘텐츠 품질 기준 R11

적용 범위: `category=음식` 신규 글과 기존 글 전체 재작성

이 문서는 음식 글의 **독자 만족·정보 깊이·벤치마크·정보 밀도·표·반복 제거·실용성**을 규정한다. 소제목은 `PROJECT_INSTRUCTIONS_FOOD_R8.1.txt`의 사용자 확정 6개 기준을 그대로 따른다.

## 1. 최우선 목표
- 목표는 형식이나 검토 항목을 채우는 것이 아니라 일반 독자가 추가 검색 없이 핵심 내용을 이해하고 실제 선택·섭취·보관에 활용할 수 있게 하는 것이다.
- 사실 확인은 작성 과정의 내부 절차이며, 확인 과정 자체를 독자용 콘텐츠로 전환하지 않는다.
- 내용이 얕으면 문장·표·강조를 늘리지 말고 정보를 더 조사한다.

## 2. 사용자 확정 6개 소제목

## 3. 기존 글 전체 재작성 — 원문 격리와 새 원고 원칙
기존 음식 URL을 최신화하거나 재작성할 때는 기존 글을 고쳐 쓰지 않는다.

- 유지 대상은 숫자 URL·주제·카테고리·중복 방지용 식별 정보뿐이다.
- 기존 본문의 문장·문단·표·강조·소제목 배치·출처 목록을 새 원고의 초안으로 사용하지 않는다.
- 기존 문장을 복사한 뒤 어휘만 바꾸거나, 문단을 이동하거나, 일부 표·사진·강조만 교체하는 방식은 전체 재작성으로 인정하지 않는다.
- 작성은 **빈 문서**에서 시작한다.
- 순서는 `정확한 검색어 확인 → 벤치마크 → 독자 질문 지도 → 새 조사 → 사실 검증 → 정보 선별 → 6개 소제목 재구성 → 새 문장 작성 → 표·강조·이미지 재선정`이다.
- 새 원고가 완성되기 전에는 기존 본문을 내용 재료로 사용하지 않는다.
- 새 원고 완성 후 누락 점검을 위해 기존 글을 대조할 수는 있다. 이때 되살릴 가치가 있는 정보도 새 자료로 다시 검증한 뒤 새 문장으로 작성한다.
- 사용자가 `제목만`, `오탈자만`, `특정 문장만`, `사진만`, `표 하나만`처럼 범위를 명시했을 때만 부분 수정을 허용한다.
- 범위를 따로 지정하지 않은 기존 음식 글 작업은 모두 **전면 신규 작성**으로 처리한다.

## 4. 작성 전 벤치마크
신규 글과 전체 재작성은 작성 전에 우수 음식·건강 콘텐츠를 3~5개 정도 확인한다.

벤치마크에서 보는 것은 다음뿐이다.
- 독자가 반복해서 묻는 질문
- 우수 콘텐츠가 공통으로 다루는 정보 범위
- 실제 구매·섭취·보관에 도움 되는 비교와 팁
- 우리 글에서 빠뜨리기 쉬운 질문
- 우리 글에서 더 쉽게 설명할 수 있는 부분

문장·수치·주장을 복사하지 않는다. 벤치마크는 **정보 범위와 독자 질문을 발견하는 절차**다.

## 5. 생활정보 조사
- 음식의 정체, 맛·식감, 종류, 제철·산지, 핵심 영양, 먹는 법, 제품 형태 차이, 궁합, 주의사항, 구매·보관 정보를 폭넓게 찾는다.
- 독자가 실제로 선택하거나 행동하는 데 필요한 정보가 먼저다.
- 수치·영양·건강·안전 정보는 신뢰 가능한 자료로 사실 여부를 확인한다.
- 확인해서 사용할 수 없는 내용은 생략하고 독자에게 필요한 다른 생활정보를 더 조사한다.

## 6. 정보 밀도
### 6.1 새 정보 원칙
- 핵심 문단 하나는 최소 하나의 새로운 사실·선택·행동 정보를 제공한다.
- 같은 사실을 도입·본문·표·요약에서 표현만 바꿔 반복하지 않는다.
- 중요한 핵심을 요약에서 한 번 다시 말할 수 있지만 반복 자체를 정보량으로 보지 않는다.

### 6.2 산술 반복 금지
다음은 저가치 반복으로 본다.
- 100mL 값을 200mL로 단순 2배 계산해 별도 열을 만드는 것
- 1개 값을 2개·3개로 단순 곱해 여러 행으로 만드는 것
- 같은 값을 g·mg·%로 의미 없이 반복하는 것
- 본문 수치를 비교 의미 없이 표에 그대로 복사하는 것

기준량을 둘 이상 보여줄 때는 각각이 실제로 다른 독자 질문에 답해야 한다.

## 7. 표 작성 기준
표는 비교 또는 수치 확인이 문장보다 빠를 때 사용한다.

좋은 예:
- 일반 우유 / 저지방 / 무지방 / 락토프리의 실제 선택 차이
- 생연어 / 훈제연어의 나트륨·용도 차이
- 품종·가공형태별 맛·용도·보관 차이
- 식품영양성분DB처럼 **신뢰 가능한 단일 기준의 핵심 영양성분 수치**를 짧게 보여주는 표

나쁜 예:
- 100mL / 200mL 단순 배수
- 같은 내용을 문장과 표로 중복
- 숫자가 있다는 이유만으로 만든 영양표
- 대부분의 행·열이 독자의 선택을 바꾸지 않는 표
- `확인 항목 / 왜 중요한가 / 실전 확인법`처럼 문장을 억지로 칸에 나눈 매트릭스

표를 넣기 전에 확인한다.
1. 각 열이 다른 질문에 답하는가?
2. 각 행이 새로운 판단을 주는가?
3. 표가 없으면 이해가 더 어려운가?
4. 단순 계산으로 칸을 채우고 있지 않은가?

### 영양 수치 표현
- **같은 기준량에서 열량·단백질·지방·탄수화물·무기질 등 핵심 영양 수치를 3개 이상 함께 제시할 때는 특별한 이유가 없으면 짧은 표로 정리한다.**
- 여러 영양 수치를 한 문장에 쉼표로 길게 나열하는 방식을 기본값으로 사용하지 않는다.
- 표에는 수치를 빠르게 비교·확인하는 역할만 맡기고, 단백질·칼슘·식이섬유·핵심 성분이 몸에서 하는 역할과 음식 고유 특징은 표 아래 서술형으로 설명한다.
- 단 하나의 수치나 짧은 두 수치만 필요한 경우, 또는 표가 오히려 읽기 흐름을 끊는 경우에는 문장으로 설명할 수 있다.

### 표 정렬
- **다음 음식 글부터 표의 헤더와 본문 셀은 기본적으로 가운데 정렬한다.**
- 숫자·종류·맛·특징·섭취법처럼 짧게 비교하는 표는 모든 열을 가운데 정렬해 시선 이동을 줄인다.
- 아주 긴 설명문이 들어가는 예외적 표만 가독성을 위해 좌측 정렬을 허용한다.
- 이번 `/116 홍차` 글은 소급 수정하지 않는다.

## 8. 소제목별 품질 기준
### 소개
- 음식의 정체, 이름, 종류, 맛·식감, 제철·산지, 유통 형태 등 처음 보는 독자가 필요한 기본 정보를 충분히 준다.
- **제철 정보는 소개에 둔다.** 섭취법이나 다른 소제목으로 밀어 넣지 않는다.

### 영양소·핵심 성분
- 핵심 영양소와 성분을 나열만 하지 않고 몸에서 어떤 역할을 하는지 쉬운 말로 설명한다.
- 일반 영양표가 음식 고유 특징을 밀어내지 않게 한다.
- **동일 기준량의 핵심 영양 수치가 3개 이상이면 짧은 표를 우선하고, 성분의 의미와 음식 고유 특징은 본문에서 설명한다.**

### 꾸준 섭취 변화
- 꾸준히 섭취했을 때 기대할 수 있는 **긍정적인 신체 변화와 건강상 이점**을 중심으로 설명한다.
- 체중 관리, 근육 유지·회복, 심혈관 건강, 뇌·인지 기능, 에너지 대사, 장 건강, 뼈 건강, 면역·피부 등은 예시이며 음식 특성에 맞는 영역을 폭넓게 확인한다.
- 독자가 읽자마자 `꾸준히 먹으면 몸에 어떤 변화가 기대되는지` 알 수 있어야 한다.
- **생활 편의·조리 편의·보관 편의·식사 지속성은 이 소제목의 핵심 내용으로 사용하지 않는다.** 필요하면 소개나 고르는 법·보관법으로 보낸다.
- 사실 확인에 사용한 자료의 유형·분석 방식·검증 단계는 독자용 본문에 나열하지 않는다.
- `무엇이 좋아질 수 있는지 → 왜 그런지 → 일상에서 어떤 의미인지`를 쉬운 말로 설명한다.
- 확인할 수 없는 효능은 제외하되, 확인 가능한 장점까지 소극적인 표현으로 축소하지 않는다.

### 궁합·시너지
- 무엇과 먹을지, 왜 좋은지, 어떻게 먹을지까지 연결한다.
- 영양 보완과 맛·식감 조합을 모두 실용적으로 설명할 수 있다.
- 과장된 치료·예방 시너지로 쓰지 않는다.
- 실제 조합은 긴 표보다 **짧은 목록 + 한두 문장 설명**을 우선한다.

### 주의사항
- 독자가 행동을 바꿔야 하는 실제 주의만 넣는다.
- 알레르기·독성·과다섭취·중요한 상호작용·특정 상황을 명확하게 설명한다.
- 일반적인 부정·제한 문장을 늘어놓지 않는다.

### 고르는 법·보관법
- 신선도, 구매 기준, 제품 형태, 보관 위치·기간·방법, 손질·조리 팁을 구체적으로 제공한다.
- 광고 문구보다 원재료명·함량·영양정보·보관조건처럼 실제 판단 기준을 우선한다.

## 9. 본문 균형과 요약 방식
- 글의 대부분은 음식의 특징·영양·장점·활용·섭취·선택·보관 정보여야 한다.
- 부정·제한·반박 문장이 글의 첫인상이나 대부분을 차지하지 않게 한다.
- 안전상 필요한 내용은 주의사항에 집중한다.
- 독자의 행동에 꼭 필요하지 않은 부정 설명은 추가하지 않는다.
- **설명·해석·효능·활용은 서술형을 기본으로 한다. 영양성분 수치·종류별 차이·가공형태 비교처럼 표가 더 빠르게 읽히는 정보는 표를 우선한다.**
- 한 글에서 표가 꼭 필요하지 않다면 0개도 허용한다. 반대로 표가 실제로 더 빠르게 읽히는 정보라면 개수를 억지로 줄이지 않는다. 표 개수를 목표로 맞추지 않는다.

### 9.1 요약 품질
- 요약은 문장을 단순히 짧게 만드는 작업이 아니라 **핵심 정보의 밀도를 높이는 작업**으로 본다.
- 좋은 요약은 가능한 짧은 문장 안에 **무엇인지 / 왜 중요한지 / 독자가 어떻게 선택·섭취·보관하면 되는지** 중 필요한 정보를 함께 담는다.
- `몸에 좋다`, `영양이 풍부하다`, `주의가 필요하다`처럼 정보가 거의 없는 추상 요약은 사용하지 않는다.
- 한 소제목에 정보가 여러 갈래로 나뉘면 서술형 설명 뒤에 **핵심 결론 1문장, 필요하면 최대 2문장**으로 정리한다. 이미 짧고 명확한 소제목에는 요약을 억지로 덧붙이지 않는다.
- 요약은 본문의 복사가 아니라 독자가 기억할 **결론·비교·숫자·실천 행동**을 압축해서 남겨야 한다.
- 전문용어는 꼭 필요할 때만 쓰고, 같은 의미라면 일반 독자가 바로 이해할 수 있는 쉬운 표현을 우선한다.

### 9.2 카드·목록에 내용을 억지로 맞추지 않는다
- `생선`, `고구마`, `닭고기`처럼 **짧은 대상명·재료명·키워드**는 왼쪽 짧은 라벨 + 오른쪽 설명 형태의 카드와 잘 맞는다.
- `색이 진한 식물성 식품의 다양성 늘리기`, `소량으로 식사의 풍미 바꾸기`처럼 **긴 행동형·서술형 제목**은 좁은 라벨 칸에 넣지 않는다.
- 긴 제목은 카드 상단 전체 폭의 제목 + 아래 설명 구조 또는 자연스러운 서술형 문단을 사용한다.
- 디자인 칸에 맞추기 위한 부자연스러운 강제 줄바꿈, 제목 축약, 문장 분절을 하지 않는다. **정보 구조에 맞는 디자인을 고르고, 디자인에 내용을 끼워 맞추지 않는다.**

## 10. 강조 품질
강조 우선순위:
1. 음식의 핵심 장점
2. 중요한 영양소·핵심 성분의 역할
3. 실제 섭취 행동
4. 좋은 궁합과 이유
5. 구매·보관 기준
6. 꼭 필요한 안전 행동

- **굵은 글씨는 가장 낮은 단계의 강조이므로 형광펜·밑줄보다 넓게 사용한다.** 일반 독자가 본문을 훑어볼 때 먼저 잡아야 할 긍정적인 특징, 확인된 장점, 영양상 이점, 좋은 궁합, 맛·식감·활용상의 강점, 실용적인 섭취·선택 팁은 굵게 표시할 수 있다.
- 굵은 글씨는 한 문단 전체가 아니라 **핵심 단어·짧은 구절·핵심 결론** 중심으로 사용해 긴 본문이 단조롭게 보이지 않게 한다.
- 일반 본문에서는 긍정·실용 정보를 우선해 굵게 표시하고, 주의사항에서는 실제 안전 행동을 바꾸는 핵심어 정도만 굵게 표시한다.
- 굵은 글씨의 개수를 목표로 정하지 않는다. 굵은 글씨를 늘리기 위해 새 문장·근거 없는 장점·반복 문장을 만들지 않는다.
- 형광펜과 밑줄은 더 높은 단계의 강조로 유지하고, 실제 우선순위가 높은 핵심 장점이나 실천 행동에만 사용한다.
- 부정 문장·제한 문장·검토용 표현을 강조 개수 채우기용으로 올리지 않는다.

## 11. 저장 전 통합 품질 검토
- 기존 글 전체 재작성이라면 기존 본문을 초안·재료로 사용하지 않고 빈 문서에서 새 조사로 작성했는가?
- 사용자 확정 6개 소제목을 그대로 사용했는가?
- 독자가 추가 검색 없이 핵심 내용을 이해할 수 있는가?
- 각 소제목이 서로 다른 새 정보를 주는가?
- **③ 꾸준 섭취 변화가 독자가 기대하는 긍정적 신체 변화 중심으로 작성됐는가?**
- **③ 본문이 작성 과정 설명이 아니라 독자가 체감할 변화와 실제 의미에 집중하는가?**
- 장점·활용·선택·섭취·보관 정보가 충분한가?
- 확인해서 사용할 수 없는 내용 대신 다른 유용한 정보를 충분히 조사했는가?
- 같은 사실을 숫자·표현만 바꿔 반복하지 않았는가?
- 표의 각 행·열이 실제 선택 정보를 주는가?
- **동일 기준량의 핵심 영양 수치 3개 이상을 한 문장에 길게 나열하고 있지 않은가? 그렇다면 표가 더 빠르게 읽히는지 우선 판단했는가?**
- 표를 사용했다면 짧은 비교표는 가운데 정렬했는가?
- 설명이 긴 소제목은 마지막 요약이 단순 반복이 아니라 결론·비교·행동을 압축해 주는가?
- 긴 서술형 문장을 좁은 라벨 칸에 억지로 넣어 강제 줄바꿈이 생기지 않았는가?
- 주의사항이 다른 소제목을 침범하거나 글 전체를 압도하지 않는가?
- 사실 확인 과정 설명이 독자용 본문을 차지하지 않는가?
