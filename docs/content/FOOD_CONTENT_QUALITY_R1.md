# 음식 콘텐츠 품질 기준 R15

적용 범위: `category=음식` 신규 글과 기존 글 전체 재작성

이 문서는 음식 글의 **독자 만족·정보 깊이·벤치마크·정보 밀도·표·반복 제거·실용성**을 규정한다. 소제목은 `PROJECT_INSTRUCTIONS_FOOD_R8.1.txt`의 사용자 확정 6개 기준을 그대로 따른다.

## 1. 최우선 목표
- 목표는 형식이나 검토 항목을 채우는 것이 아니라 일반 독자가 추가 검색 없이 핵심 내용을 이해하고 실제 선택·섭취·보관에 활용할 수 있게 하는 것이다.
- 사실 확인은 작성 과정의 내부 절차이며, 확인 과정 자체를 독자용 콘텐츠로 전환하지 않는다.
- 내용이 얕으면 문장·표·강조를 늘리지 말고 정보를 더 조사한다.

## 2. 사용자 확정 6개 소제목
1. 소개
2. 영양소·핵심 성분
3. 꾸준 섭취 변화

이 이름·순서·의미는 사용자의 별도 지시 없이 바꾸지 않는다.

## 3. 기존 글 전체 재작성 — 원문 격리와 새 원고 원칙
기존 음식 URL을 최신화하거나 재작성할 때는 기존 글을 고쳐 쓰지 않는다.

- 유지 대상은 숫자 URL·주제·카테고리·중복 방지용 식별 정보뿐이다.
- 기존 본문의 문장·문단·표·강조·소제목 배치·출처 목록을 새 원고의 초안으로 사용하지 않는다.
- 기존 문장을 복사한 뒤 어휘만 바꾸거나, 문단을 이동하거나, 일부 표·사진·강조만 교체하는 방식은 전체 재작성으로 인정하지 않는다.
- 작성은 **빈 문서**에서 시작한다.
- 순서는 `정확한 검색어 확인 → 벤치마크 → 독자 질문 지도 → 새 조사 → 사실 검증 → 정보 선별 → 6개 소제목 재구성 → 새 문장 작성 → 표·강조·이미지 재선정`이다.
- 새 원고가 완성되기 전에는 기존 본문을 내용 재료로 사용하지 않는다.
- 새 원고 완성 후 누락 점검을 위해 기존 글을 대조할 수는 있다. 이때 되살릴 가치가 있는 정보도 새 자료로 다시 검증한 뒤 새 문장으로 작성한다.
- 사용자가 `제목만`, `오탈자만`, `특정 문장만`, `사진만`, `표 하나만`처럼 범위를 명시했을 때만 부분 수정을 허용한다.
- 범위를 따로 지정하지 않은 기존 음식 글 작업은 모두 **전면 신규 작성**으로 처리한다.

## 4. 작성 전 벤치마크
신규 글과 전체 재작성은 작성 전에 우수 음식·건강 콘텐츠를 3~5개 정도 확인한다.

벤치마크에서 보는 것은 다음뿐이다.
- 독자가 반복해서 묻는 질문
- 우수 콘텐츠가 공통으로 다루는 정보 범위
- 실제 구매·섭취·보관에 도움 되는 비교와 팁
- 우리 글에서 빠뜨리기 쉬운 질문
- 우리 글에서 더 쉽게 설명할 수 있는 부분

문장·수치·주장을 복사하지 않는다. 벤치마크는 **정보 범위와 독자 질문을 발견하는 절차**다.

## 5. 생활정보 조사
- 음식의 정체, 맛·식감, 종류, 제철·산지, 핵심 영양, 먹는 법, 제품 형태 차이, 궁합, 주의사항, 구매·보관 정보를 폭넓게 찾는다.
- 독자가 실제로 선택하거나 행동하는 데 필요한 정보가 먼저다.
- **영양 조사에서는 기본값으로 `열량(kcal)·탄수화물·단백질·지방`을 먼저 확인한다.** 음식 특성에 따라 당류·식이섬유·나트륨·비타민·무기질·고유 성분을 추가한다.
- 생것·말린 것·분말·농축액·음료·통조림 등 형태에 따라 값이 달라지면 **어떤 형태와 기준량의 값인지 먼저 확정**하고, 독자가 자주 접하는 형태가 여러 개면 실제 선택에 도움이 되는 범위에서 비교한다.
- 수치·영양·건강·안전 정보는 신뢰 가능한 자료로 사실 여부를 확인한다.
- 검증되지 않은 치료·예방 효능의 확정 표현만 제외한다. 자료에 실제로 있는 음식 고유 성분의 측정값, 세포·동물·사람 연구에서 관찰된 작용은 근거 수준에 맞게 살려 독자가 이해할 수 있도록 설명한다.

### 5.1 구매 추천 TOP3 — 완제품 우선, 산지·품종 대체
- 홍삼·요거트·오트밀·견과버터처럼 **브랜드 완제품을 실제로 비교해 사는 비중이 큰 음식**은 ⑥ `고르는 법·보관법`에서 추천 제품 TOP3를 추가할 수 있다.
- 추천 순위는 판매량·리뷰 수·인지도 순으로 정하지 않는다. **제품의 실제 표시정보와 현재 가격을 비교해 편집자가 가장 낫다고 판단한 순위**로 작성한다.
- 기본 비교축은 `핵심 성분/기능성 함량`, `1일 섭취 비용`, `당류·나트륨·불필요한 첨가 원료`, `섭취 편의성`, `제품 정보 투명성`이다. 음식 특성에 따라 평가축을 추가·삭제할 수 있다.
- 건강기능식품은 제조사 공식 페이지와 식품의약품안전처 건강기능식품 신고정보를 우선하고, 가격은 공식몰 또는 확인 가능한 현재 판매처를 추가 확인한다.
- 제품별 가격은 행사·구성에 따라 변하므로 **확인 날짜와 가격 변동 가능성**을 함께 알린다.
- 등록 DB·공식 페이지·유통 라벨 수치가 서로 다르면 차이를 숨기지 않는다. 현재 유통 라벨을 확정할 수 없으면 해당 항목을 감점하거나 추천에서 제외하고, 포함할 경우 반드시 차이를 설명한다.
- `1위`는 판매량 1위가 아니라 **종합 추천**, `고함량`, `가성비`, `저당`, `편의성`처럼 왜 좋은지 독자가 바로 이해할 수 있게 선정 이유를 붙인다.
- 협찬·광고·제휴 여부가 없다면 없는 것처럼 가장하지 않고, **공개된 제품 정보에 따른 편집 비교**라는 점을 명확히 한다. 향후 제휴 링크를 사용하더라도 순위 산식과 추천 판단을 제휴 수익에 맞춰 바꾸지 않는다.
- **생과일·생선·채소·원물처럼 브랜드 제품 비교가 의미 없는 음식은 추천을 통째로 생략하지 말고, 산지·품종·생산 방식이 실제 구매 판단에 차이를 만드는지 먼저 확인한다.**
- 산지·품종 비교가 유용하고 공공기관·생산지 공식자료·농업/수산 전문자료로 비교 근거를 확인할 수 있으면 `지역/산지/품종 편집 추천 TOP3`로 대체할 수 있다.
- 산지·품종 TOP3의 기본 비교축은 `재배·생산 환경`, `산지 규모와 전문성`, `선별·품질관리`, `대표 품종`, `유통·신선도`, `실제 구매 차이`다. 음식 특성에 따라 조정한다.
- 지역 순위도 판매량 하나만으로 정하지 않으며, **공식 순위가 아니라 편집 비교**임을 밝힌다.
- 동일 품종·같은 숙도·같은 시기의 직접 성분 분석자료가 없으면 `어느 지역이 영양성분이 더 높다`고 단정하지 않는다. 성분 차이는 가능성으로 설명하고 순위는 구매 품질·산지 전문성 중심으로 판단한다.
- 지역명만 반복하는 광고성 설명보다 `왜 1·2·3위인지`, `어떤 품종/목적에 맞는지`를 짧게 설명한다.

## 6. 정보 밀도
### 6.1 새 정보 원칙
- 핵심 문단 하나는 최소 하나의 새로운 사실·선택·행동 정보를 제공한다.
- 같은 사실을 도입·본문·표·요약에서 표현만 바꿔 반복하지 않는다.
- 중요한 핵심을 요약에서 한 번 다시 말할 수 있지만 반복 자체를 정보량으로 보지 않는다.

### 6.2 산술 반복 금지
다음은 저가치 반복으로 본다.
- 100mL 값을 200mL로 단순 2배 계산해 별도 열을 만드는 것
- 1개 값을 2개·3개로 단순 곱해 여러 행으로 만드는 것
- 같은 값을 g·mg·%로 의미 없이 반복하는 것
- 본문 수치를 비교 의미 없이 표에 그대로 복사하는 것

기준량을 둘 이상 보여줄 때는 각각이 실제로 다른 독자 질문에 답해야 한다.

## 7. 표 작성 기준
표는 비교 또는 수치 확인이 문장보다 빠를 때 사용한다.

좋은 예:
- 일반 우유 / 저지방 / 무지방 / 락토프리의 실제 선택 차이
- 생연어 / 훈제연어의 나트륨·용도 차이
- 품종·가공형태별 맛·용도·보관 차이
- 식품영양성분DB처럼 **신뢰 가능한 단일 기준의 핵심 영양성분 수치**를 짧게 보여주는 표
- 실제 완제품 3개를 `핵심 성분·1일 비용·당류/첨가물·섭취 편의성·선정 이유`로 비교하는 추천 TOP3 표
- 원물 음식에서 제품 비교가 의미 없을 때 산지 3곳을 `재배환경·품질관리·대표 품종·추천 대상`으로 비교하는 편집 추천 표

나쁜 예:
- 100mL / 200mL 단순 배수
- 같은 내용을 문장과 표로 중복
- 숫자가 있다는 이유만으로 만든 영양표
- 대부분의 행·열이 독자의 선택을 바꾸지 않는 표
- `확인 항목 / 왜 중요한가 / 실전 확인법`처럼 문장을 억지로 칸에 나눈 매트릭스
- 판매량·리뷰 수만으로 순위를 매긴 제품 추천표
- 비교 가능한 직접 분석자료 없이 지역별 영양성분 우열을 단정한 표

표를 넣기 전에 확인한다.
1. 각 열이 다른 질문에 답하는가?
2. 각 행이 새로운 판단을 주는가?
3. 표가 없으면 이해가 더 어려운가?
4. 단순 계산으로 칸을 채우고 있지 않은가?

### 영양 수치 표현
- **모든 음식 글의 ② 영양소·핵심 성분에는 대표 기준량이 명확한 기본 영양정보가 있어야 한다. 기본 세트는 열량(kcal)·탄수화물·단백질·지방이며, 음식 특성상 중요한 경우 당류·식이섬유·나트륨을 추가한다.**
- **기본 영양표와 고유 기능성 성분을 한 묶음으로 조사한다.** 홍삼의 진세노사이드, 녹차의 카테킨, 케이퍼의 루틴·퀘르세틴·캠페롤처럼 음식 고유 성분을 실제 함량·작용과 함께 다룬다. 칼로리·3대 영양소도 유지하며 서로 다른 정보가 상대를 밀어내지 않게 한다.
- 같은 기준량에서 열량·단백질·지방·탄수화물·무기질 등 핵심 영양 수치를 3개 이상 함께 제시할 때는 특별한 이유가 없으면 짧은 표로 정리한다.
- 여러 영양 수치를 한 문장에 쉼표로 길게 나열하는 방식을 기본값으로 사용하지 않는다.
- 표에는 수치를 빠르게 비교·확인하는 역할만 맡기고, 단백질·칼슘·식이섬유·핵심 성분이 몸에서 하는 역할과 음식 고유 특징은 표 아래 서술형으로 설명한다.

- **독자가 가장 먼저 알고 싶은 것은 `다른 음식과 비교해 무엇이 풍부한가`다.** 단백질·칼슘·철·비타민·식이섬유 등 중요한 성분은 신뢰 가능한 동일 식품형 자료로 확인하고, 특징적인 성분을 표와 표 아래에서 먼저 구별한다. 대표 성분이 실제 양에서는 적다면 `풍부하다`라고 쓰지 않는다.
- 100g 값만 제시하지 말고 **실제 한 번 먹는 양**과 **성인 1일 영양성분 기준치 대비 비율(%)**을 중요한 영양소에 한해 덧붙인다. 특히 케이퍼 같은 소량 양념, 견과버터·분말·말린 식품은 100g만으로 영양상 강점을 판단하면 안 된다. 현실적인 1회 제공량이 검증 불가능한 경우에는 임의로 만들지 않고 기준량과 한계를 설명한다.
- 국내 독자에게는 가능한 한 **대한민국 식품표시 법령의 `1일 영양성분 기준치`**를 공통 비교축으로 사용한다(예: 나트륨 2,000mg, 칼슘 700mg, 철분 12mg, 식이섬유 25g, 비타민 K 70㎍; 법령 개정 시 최신 수치 확인). 이것은 사람마다 다른 실제 권장섭취량이나 질병별 처방량이 아니라 **영양표시용 공통 기준**이다. `섭취량÷기준치×100`으로 계산하고 반올림·출처·식품형·1회 중량을 드러낸다.
- **영양상 강점과 제한 사항을 구분한다.** 칼슘처럼 유익한 영양소는 실제 섭취량 대비 기여도가 충분할 때 강조하고, 나트륨·첨가당처럼 줄이는 것이 유리한 성분은 `주의해야 할 높은 함량`으로 설명한다. 높은 비율이라고 무조건 긍정 효능 형광펜을 적용하지 않는다.
- 영양표는 `성분 / 공통 비교 기준(예: 100g) / 실제 1회량과 1일 기준치 비율`처럼 모바일에서 읽을 수 있는 최소 열 수를 권장한다. 비율을 붙일 근거가 없는 고유 폴리페놀·항산화 성분은 가짜 권장량이나 %를 만들지 않고 확인 가능한 정량값·특징만 설명한다.
- **제출 전 질문:** `형광펜·표에서 이 음식에 실제로 풍부한 영양소, 그렇지 않은 영양소, 특히 조절할 성분을 구별할 수 있는가?` 대답이 불가능하면 수치 나열형 표를 완성으로 보지 않는다.
- 생것·말린 것·농축액·분말·음료처럼 형태별 수치 차이가 크면 **표 제목 또는 바로 앞 문장에서 형태와 기준량을 명시**한다. 제품별 차이가 큰 가공식품은 대표 식품형 기본값과 실제 제품 영양성분표를 혼동하지 않게 구분한다.
- 단 하나의 수치나 짧은 두 수치만 필요한 경우, 또는 표가 오히려 읽기 흐름을 끊는 경우에는 문장으로 설명할 수 있다. 다만 **열량을 포함한 기본 영양정보 자체를 통째로 생략하는 예외로 사용하지 않는다.**

### 표 정렬
- **다음 음식 글부터 표의 헤더와 본문 셀은 기본적으로 가운데 정렬한다.**
- 숫자·종류·맛·특징·섭취법처럼 짧게 비교하는 표는 모든 열을 가운데 정렬해 시선 이동을 줄인다.
- 아주 긴 설명문이 들어가는 예외적 표만 가독성을 위해 좌측 정렬을 허용한다.
- 이번 `/116 홍차` 글은 소급 수정하지 않는다.

## 8. 소제목별 품질 기준
### 소개
- 음식의 정체, 이름, 종류, 맛·식감, 제철·산지, 유통 형태 등 처음 보는 독자가 필요한 기본 정보를 충분히 준다.
- **제철 정보는 소개에 둔다.** 섭취법이나 다른 소제목으로 밀어 넣지 않는다.

### 영양소·핵심 성분
- 핵심 영양소와 성분을 나열만 하지 않고 몸에서 어떤 역할을 하는지 쉬운 말로 설명한다.
- **기본 영양정보와 음식 고유 핵심성분을 모두 확보 → 성분별 확인된 작용을 구체적으로 설명 → 식품 형태·실제 섭취량의 차이를 정리**한다. 기본 영양 수치만으로 음식의 고유 장점을 대체하지 않는다.
- 열량·탄수화물·단백질·지방을 빠뜨린 채 기능성 성분·효능 기준만 설명하지 않는다.
- 동일 기준량의 핵심 영양 수치가 3개 이상이면 짧은 표를 우선하고, 성분의 의미와 음식 고유 특징은 본문에서 설명한다.
- 일반 영양표가 음식 고유 특징을 밀어내지 않게 하되, 반대로 음식 고유 특징이 기본 영양표를 밀어내지도 않게 한다.

### 꾸준 섭취 변화
- 꾸준히 섭취했을 때 기대할 수 있는 **긍정적인 신체 변화와 건강상 이점**을 중심으로 설명한다.
- 체중 관리, 근육 유지·회복, 심혈관 건강, 뇌·인지 기능, 에너지 대사, 장 건강, 뼈 건강, 면역·피부 등은 예시이며 음식 특성에 맞는 영역을 폭넓게 확인한다.
- 독자가 읽자마자 `꾸준히 먹으면 몸에 어떤 변화가 기대되는지` 알 수 있어야 한다.
- **생활 편의·조리 편의·보관 편의·식사 지속성은 이 소제목의 핵심 내용으로 사용하지 않는다.** 필요하면 소개나 고르는 법·보관법으로 보낸다.
- 사실 확인에 사용한 자료의 유형·분석 방식·검증 단계는 독자용 본문에 나열하지 않는다.
- `무엇이 좋아질 수 있는지 → 왜 그런지 → 일상에서 어떤 의미인지`를 쉬운 말로 설명한다.
- 성분 자체의 작용(세포·동물 등 연구 단계)과 실제 음식 섭취에서 확인된 신체 변화(사람 연구·영양상 역할)를 분리해 둘 다 유용한 범위에서 설명한다. 효과가 확인되지 않은 부분을 확정 치료·예방 효능으로 바꾸지 않되, 확인된 성분과 연구 결과를 통째로 제외하지 않는다.

**③ 조사 누락 차단:** 같은 혈중지질 축의 LDL·총콜레스테롤·중성지방은 건강 변화 3종이 아니라 한 신체 영역의 지표 3개다. 먼저 음식 특성에 맞는 인지·뇌, 체중·포만감, 혈당·대사, 장·미생물, 면역·염증, 심혈관·혈압, 근육·뼈 등 복수 영역을 조사한다. 실제로 확인된 긍정적 변화는 `변화 → 관찰된 조건/기간 → 근거 수준 → 독자에게 의미`까지 서술하고, 근거가 부족한 효과는 만들어내지 않는다. 세 영역 미만만 근거가 있다면 나머지 최소 2개 영역을 포함해 네 가지 이상의 영역을 찾아본 근거와 제외 이유를 원고 source의 `foodBenefitScopeReview`에 남긴다. 본문에 조사의 실패 과정을 쏟아내지 않는다. **신체 영역을 세 개 이상 썼다는 사실만으로 실제 효과가 검증된 것은 아니다.**

### 궁합·시너지
- 무엇과 먹을지, 왜 좋은지, 어떻게 먹을지까지 연결한다.
- 영양 보완과 맛·식감 조합을 모두 실용적으로 설명할 수 있다.
- 과장된 치료·예방 시너지로 쓰지 않는다.
- 실제 조합은 긴 표보다 **짧은 목록 + 한두 문장 설명**을 우선한다.

### 주의사항
- 독자가 행동을 바꿔야 하는 실제 주의만 넣는다.
- 알레르기·독성·과다섭취·중요한 상호작용·특정 상황을 명확하게 설명한다.
- 일반적인 부정·제한 문장을 늘어놓지 않는다.

### 고르는 법·보관법
- 신선도, 구매 기준, 제품 형태, 보관 위치·기간·방법, 손질·조리 팁을 구체적으로 제공한다.
- 광고 문구보다 원재료명·함량·영양정보·보관조건처럼 실제 판단 기준을 우선한다.
- 브랜드 완제품 비교가 구매에 실질적으로 도움이 되는 음식은 **추천 제품 TOP3**를 추가할 수 있다. 이때 판매량 순위가 아니라 `핵심성분/기능성 함량·1일 비용·당류/첨가물·편의성·정보 투명성`을 종합 비교해 순위를 정한다.
- 브랜드 비교가 의미 없는 원물은 **산지·품종 차이가 실제 구매 선택에 도움이 되는지 확인한 뒤, 근거가 충분하면 지역/산지/품종 편집 추천 TOP3로 대체**한다.
- 추천 제품·지역마다 **왜 선택했는지와 누구에게 맞는지**를 짧게 설명한다.
- 원자료가 서로 충돌하거나 현재 비교 근거를 충분히 확인할 수 없으면 억지로 TOP3를 만들지 않는다.
- 추천 정보를 추가하더라도 **기존에 승인된 카드·목록·표의 전체 작성 양식을 임의로 바꾸지 않는다.** 기존 양식 안에 비교표나 짧은 추천 블록을 추가하는 것을 우선한다.

## 9. 본문 균형과 요약 방식
- 글의 대부분은 음식의 특징·영양·장점·활용·섭취·선택·보관 정보여야 한다.
- 부정·제한·반박 문장이 글의 첫인상이나 대부분을 차지하지 않게 한다.
- 안전상 필요한 내용은 주의사항에 집중한다.
- 독자의 행동에 꼭 필요하지 않은 부정 설명은 추가하지 않는다.
- **설명·해석·효능·활용은 서술형을 기본으로 한다. 영양성분 수치·종류별 차이·가공형태 비교처럼 표가 더 빠르게 읽히는 정보는 표를 우선한다.**
- 한 글에서 표가 꼭 필요하지 않다면 0개도 허용한다. 다만 **② 기본 영양정보가 숫자 3개 이상이면 짧은 표를 우선하며, 기본 영양정보 자체를 생략하기 위한 이유로 `표 0개 허용` 규칙을 사용하지 않는다.**

### 9.1 요약 품질
- 요약은 문장을 단순히 짧게 만드는 작업이 아니라 **핵심 정보의 밀도를 높이는 작업**으로 본다.
- 좋은 요약은 가능한 짧은 문장 안에 **무엇인지 / 왜 중요한지 / 독자가 어떻게 선택·섭취·보관하면 되는지** 중 필요한 정보를 함께 담는다.
- `몸에 좋다`, `영양이 풍부하다`, `주의가 필요하다`처럼 정보가 거의 없는 추상 요약은 사용하지 않는다.
- 한 소제목에 정보가 여러 갈래로 나뉘면 서술형 설명 뒤에 **핵심 결론 1문장, 필요하면 최대 2문장**으로 정리한다. 이미 짧고 명확한 소제목에는 요약을 억지로 덧붙이지 않는다.
- 요약은 본문의 복사가 아니라 독자가 기억할 **결론·비교·숫자·실천 행동**을 압축해서 남겨야 한다.
- 전문용어는 꼭 필요할 때만 쓰고, 같은 의미라면 일반 독자가 바로 이해할 수 있는 쉬운 표현을 우선한다.

### 9.2 카드·목록에 내용을 억지로 맞추지 않는다
- `생선`, `고구마`, `닭고기`처럼 **짧은 대상명·재료명·키워드**는 왼쪽 짧은 라벨 + 오른쪽 설명 형태의 카드와 잘 맞는다.
- `색이 진한 식물성 식품의 다양성 늘리기`, `소량으로 식사의 풍미 바꾸기`처럼 **긴 행동형·서술형 제목**은 좁은 라벨 칸에 넣지 않는다.
- 긴 제목은 카드 상단 전체 폭의 제목 + 아래 설명 구조 또는 자연스러운 서술형 문단을 사용한다.
- 디자인 칸에 맞추기 위한 부자연스러운 강제 줄바꿈, 제목 축약, 문장 분절을 하지 않는다. **정보 구조에 맞는 디자인을 고르고, 디자인에 내용을 끼워 맞추지 않는다.**
- 새 추천 표·산지 비교를 추가한다는 이유로 이미 승인된 본문 카드 구조나 섹션 레이아웃을 다른 양식으로 교체하지 않는다.

## 10. 강조 품질
강조 우선순위:
1. 음식의 핵심 장점
2. 중요한 영양소·핵심 성분의 역할
3. 실제 섭취 행동
4. 좋은 궁합과 이유
5. 구매·보관 기준
6. 꼭 필요한 안전 행동

- **형광펜은 글 전체를 빠르게 훑기 위한 스캔 레이어다.** 총개수만 맞추는 것이 아니라 도입부터 마지막 소제목까지 읽는 흐름 전체에 고르게 배치한다.
- **도입·핵심요약·① 소개·② 영양소 구간이 형광펜 없이 길게 비어 있으면 실패로 본다.** 앞부분에도 품종 차이, 핵심 영양, 먹는 방식, 선택·보관처럼 실제 판단에 도움이 되는 내용이 있으면 자연스러운 짧은 구절을 형광펜으로 잡는다.
- 한 소제목 뒤쪽에 형광펜을 몰아넣지 않는다. 독자가 화면을 스크롤할 때 각 구간에서 최소 하나 이상의 읽을 만한 핵심 앵커가 이어져야 한다. 단, 해당 구간에 실제로 강조할 가치가 없는 문장을 억지로 올리지는 않는다.
- 형광펜은 문장 전체가 아니라 **의미가 완결되는 짧은 구절**로 잡는다. 단일 명사만 칠하거나 음식명을 억지로 반복해 조합하지 않는다.
- **굵은 글씨는 가장 낮은 단계의 강조이므로 형광펜·밑줄보다 넓게 사용한다.** 일반 독자가 본문을 훑어볼 때 먼저 잡아야 할 긍정적인 특징, 확인된 장점, 영양상 이점, 좋은 궁합, 맛·식감·활용상의 강점, 실용적인 섭취·선택 팁은 굵게 표시할 수 있다.
- 굵은 글씨는 한 문단 전체가 아니라 **핵심 단어·짧은 구절·핵심 결론** 중심으로 사용해 긴 본문이 단조롭게 보이지 않게 한다.
- 일반 본문에서는 긍정·실용 정보를 우선해 굵게 표시하고, 주의사항에서는 실제 안전 행동을 바꾸는 핵심어 정도만 굵게 표시한다.
- 굵은 글씨의 개수를 목표로 정하지 않는다. 굵은 글씨를 늘리기 위해 새 문장·근거 없는 장점·반복 문장을 만들지 않는다.
- 형광펜과 밑줄은 더 높은 단계의 강조로 유지하고, 실제 우선순위가 높은 핵심 장점이나 실천 행동에만 사용한다.
- 부정 문장·제한 문장·검토용 표현을 강조 개수 채우기용으로 올리지 않는다.

## 11. 저장 전 통합 품질 검토
- 기존 글 전체 재작성이라면 기존 본문을 초안·재료로 사용하지 않고 빈 문서에서 새 조사로 작성했는가?
- 사용자 확정 6개 소제목을 그대로 사용했는가?
- 독자가 추가 검색 없이 핵심 내용을 이해할 수 있는가?
- 각 소제목이 서로 다른 새 정보를 주는가?
- **도입부터 ② 영양소·핵심 성분까지 형광펜 스캔 앵커가 실제로 이어지는가? 앞부분이 일반 문장만 길게 이어져 독자가 빠르게 훑을 정보가 사라지지 않았는가?**
- **형광펜이 특정 후반 소제목에 몰리지 않고 글 전체에 분포하며, 각각이 짧고 자연스러운 의미 구절인가?**
- **② 영양소·핵심 성분에 기준량이 명확한 열량·탄수화물·단백질·지방이 모두 들어갔는가?**
- **고유 기능성 성분 표가 기본 영양정보를 대신하고 있지 않은가?**
- **가공 형태별 영양값 차이가 큰 음식이면 어떤 형태의 수치인지 명확히 밝혔는가?**
- **③ 꾸준 섭취 변화가 독자가 기대하는 긍정적 신체 변화 중심으로 작성됐는가?**
- **③ 본문이 작성 과정 설명이 아니라 독자가 체감할 변화와 실제 의미에 집중하는가?**
- 장점·활용·선택·섭취·보관 정보가 충분한가?
- 이 음식 고유 성분의 실제 함량·알려진 작용·연구 수준을 살렸으며, 사람 대상 효과와 혼동하지 않게 설명했는가?
- 같은 사실을 숫자·표현만 바꿔 반복하지 않았는가?
- 표의 각 행·열이 실제 선택 정보를 주는가?
- **완제품 추천 TOP3가 있는 글은 판매량·브랜드 인지도만으로 순위를 정하지 않고 실제 성분·1일 비용·당류/첨가물·편의성·정보 투명성을 비교했는가?**
- **브랜드 비교가 의미 없는 원물은 산지·품종 TOP3가 실제 구매 판단에 도움이 되는지 검토했는가? 순위를 넣었다면 공식 순위처럼 표현하지 않았고, 지역별 영양성분 우열을 근거 없이 단정하지 않았는가?**
- **추천 정보를 추가하면서 기존 승인 작성 양식·카드·목록 구조를 바꾸지 않았는가?**
- **추천 제품의 현재 가격·표시정보를 확인했고 확인 날짜와 변동 가능성을 밝혔는가? 자료가 상충하면 숨기지 않았는가?**
- **동일 기준량의 핵심 영양 수치 3개 이상을 한 문장에 길게 나열하고 있지 않은가? 그렇다면 표가 더 빠르게 읽히는지 우선 판단했는가?**
- 표를 사용했다면 짧은 비교표는 가운데 정렬했는가?
- 설명이 긴 소제목은 마지막 요약이 단순 반복이 아니라 결론·비교·행동을 압축해 주는가?
- 긴 서술형 문장을 좁은 라벨 칸에 억지로 넣어 강제 줄바꿈이 생기지 않았는가?
- 주의사항이 다른 소제목을 침범하거나 글 전체를 압도하지 않는가?
- 사실 확인 과정 설명이 독자용 본문을 차지하지 않는가?
