# 음식 로컬 기술 계약

편집 기준은 PROJECT_INSTRUCTIONS.txt다. 기술 규격은 이 저장소의 publishing/direct-authoring-contract.mjs, direct-preflight.mjs, image-review.mjs, direct-emphasis.mjs, direct-design.mjs가 담당한다.

- 이미지 출처·라이선스·검토 필드와 강조·HTML 규칙은 위 코드의 동일 검사를 작성 준비와 제출에서 사용한다.
- 실제 제출은 publishing/writer-session.mjs 안에서 source 범위·호스트·잠금을 확인한다.
- 새 글 중복 확인은 이 저장소 authoring/target-resolution과 target-resolution-results에 보관한다.
- GitHub 원장은 이 저장소 publishing/state 또는 publishing/update-state에만 저장한다.
- PUBLIC_VERIFIED는 제목·본문·이미지·대표 이미지·강조·PC/모바일 공개 반영 검증이다. 의학적 감수를 뜻하지 않는다.
- 일반 Chat은 로컬 실행 없이 이 저장소에 원고를 저장하고 이 저장소 Actions 결과를 추적한다. 실제 사용 가능한 권한이 없으면 다른 저장소로 우회하지 않는다.
