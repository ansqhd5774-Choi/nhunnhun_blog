# 음식 승인 기준 사례 R1

적용 범위: `category=음식` 신규 글과 기존 글 전면 재작성

이 문서는 최근 사용자 승인 수준을 다음 음식 글에도 재현하기 위한 **실전 기준 사례**다. 기본 소제목·내용 기준은 `PROJECT_INSTRUCTIONS_FOOD_R8.1.txt`와 `FOOD_CONTENT_QUALITY_R1.md`를 우선하고, 이 문서는 그 기준을 실제 글에 어떻게 적용할지 고정한다.

## 1. 승인 기준 사례
- 포도 `/153`: 기본 영양 + 품종/산지 차이 + 자연스러운 강조 + 원물 음식의 산지 편집 추천 TOP3가 잘 결합된 사례.
- 멸치 `/173`: 대표 영양소를 빠뜨리지 않고 **기본 영양 → 핵심 무기질/비타민 → 크기별 차이 → 실제 의미**까지 확장한 사례.
- 단호박 `/183` r5: **키워드 몇 개만 읽어도 의미가 예측되는 짧은 의미 조합**으로 형광펜을 구성한 사례. 음식명은 문맥상 필요할 때만 넣고 기계적으로 반복하지 않는다.
- 이후 음식 글은 주제 특성에 맞게 위 사례의 **정보 밀도·비교 수준·강조 밀도·추천 방식**을 기준선으로 삼는다.

## 2. ② 영양소·핵심 성분 — 대표 영양소 누락 금지
1. 먼저 그 음식이 일반적으로 무엇으로 알려져 있는지 확인한다. 예: 멸치=칼슘, 연어=단백질·오메가3, 귀리=식이섬유·베타글루칸.
2. 기본 영양은 최소 `열량·탄수화물·단백질·지방`을 확인한다.
3. 음식의 정체성을 만드는 대표 영양소/성분은 반드시 추가한다. 대표 영양소가 제목·검색의도에 들어가는데 본문 표에 빠지는 것은 실패로 본다.
4. 음식 특성에 따라 `당류·식이섬유·칼슘·인·마그네슘·칼륨·철·아연·나트륨·비타민·오메가3·폴리페놀·고유 성분` 등을 확장한다.
5. 영양 수치만 나열하지 않고 **몸에서의 역할**을 짧고 쉬운 말로 설명한다.
6. 생것/말린 것/삶은 것/분말/농축액처럼 수분·가공 차이로 수치가 크게 달라지면 형태를 명확히 표시하고 같은 음식처럼 섞어 비교하지 않는다.
7. 잔멸치·중멸치·대멸치, 품종, 가공형태처럼 독자가 실제로 구분해 구매하는 형태가 있고 영양 차이가 유의미하면 **동일 기준량 비교표**를 추가한다.
8. 100g 수치는 비교 기준이지 1회 권장섭취량으로 오해시키지 않는다.
9. 표 하나로 끝내지 말고, 표 아래에서 `어떤 성분이 특히 높은지 / 어떤 형태가 어떤 영양에 유리한지 / 실제 식사에서 어떻게 이해할지`를 해석한다.

### 멸치 `/173` 기준 예시
- 잔멸치·중멸치·대멸치의 열량·단백질·지방·탄수화물뿐 아니라 **칼슘·인·마그네슘·칼륨·나트륨**까지 비교.
- 대멸치는 추가로 **철·아연·비타민 B12·비타민 D·엽산**까지 설명.
- `멸치=칼슘`이라는 대표 검색의도를 표와 본문에서 실제 수치로 확인.
- 크기별 값이 다르면 하나의 대표값으로 뭉개지 않고 차이를 보여준다.

## 3. 형광펜 — 수량보다 스캔 이해도
- 글 앞부분부터 끝까지 형광펜이 고르게 보여야 한다. 도입·①·②가 비어 있고 뒤쪽에만 몰리면 실패다.
- 형광펜만 훑어도 음식의 정체, 핵심 영양, 꾸준 섭취 변화, 궁합, 핵심 주의, 구매/보관이 대략 연결돼야 한다.
- **서술형 문장 전체를 형광펜으로 칠하지 않는다.** 형광펜은 본문 설명문을 복사하는 영역이 아니라 스캔용 핵심 정보다.
- 목표는 `음식명을 반복하는 것`이 아니라 **키워드 몇 개만 읽고도 관계와 의미를 빠르게 예측할 수 있게 만드는 것**이다.
- 형광펜은 보통 `핵심 성분/수치 + 결과`, `궁합 음식 + 보완점`, `조건 + 행동`, `산지/품종 + 차이`처럼 2~4개의 의미 단위를 연결한다.
- 단일 명사만 강조하지 않는다. `칼슘`, `면역 기능`처럼 관계가 끊긴 조각보다 **짧은 의미 조합**으로 잡는다.
- 반대로 문장 전체를 강조하지 않는다. 조사·서술어를 줄이고 의미가 남는 핵심어끼리 연결한다.
- **음식명은 필요할 때만 쓴다.** 같은 섹션·카드 제목·앞 문장에서 대상이 이미 분명하면 `단호박`, `홍삼`, `포도`를 매 형광펜마다 반복하지 않는다.
- 음식명을 빼도 뜻이 모호하면 그때만 음식명, 품종, 대표 성분, 조합 음식 같은 앵커를 추가한다.
- 좋은 예: `베타카로틴 → 비타민A · 시각·점막 기능 유지`, `식이섬유 4.6g/100g · 배변 리듬 관리`, `무가당 요거트 · 단백질 보완 + 추가당 최소화`, `칼륨 제한 중 · 1회 섭취량 조절`.
- 나쁜 예: `단호박 베타카로틴 · ...`, `단호박 식이섬유 · ...`, `단호박 칼륨 · ...`처럼 **모든 강조 앞에 음식명을 강제로 반복**하는 형태.
- ③ 꾸준 섭취 변화는 `대표 성분/영양 + 몸의 정상 기능 또는 기대 변화`가 한눈에 연결돼야 한다. 생활 팁이나 대체 행동만 강조해 ③을 채우지 않는다.
- ④ 궁합에서는 형광펜만 읽어도 `무엇과 먹으면 무엇을 보완하는지`가 이해돼야 한다.
- ⑤ 주의사항은 `조건 + 행동`을 짧게 연결한다.
- ⑥ 고르는 법·보관법은 `좋은 제품/원물의 기준 + 핵심 특징` 또는 `보관 조건 + 방법`으로 잡는다.
- 경고보다 장점·핵심 영양·실제 섭취/선택 행동을 우선 강조한다.

## 4. 디자인·작성 양식 보존
- 신규 및 전면 재작성은 승인된 `nh-direct-v2` 카드/목록/표 구조를 사용한다.
- ③ 꾸준 섭취 변화, ④ 궁합·시너지, ⑤ 주의사항, ⑥ 고르는 법·보관법의 반복 정보는 카드 구조를 우선한다.
- 내용 보강이나 형광펜 추가 때문에 기존 승인 카드·표·박스 레이아웃을 평문으로 무너뜨리지 않는다.
- 카드 렌더링을 위해 `<li><strong>카드 제목</strong> ...</li>` 구조를 유지하고, 카드 제목보다 앞에 `<mark>`를 넣지 않는다.
- 긴 정보는 표가 읽기 빠를 때만 표로 만들고, 설명은 자연스러운 문단으로 둔다.

## 5. ⑥ 고르는 법·보관법 — 추천 TOP3 적용 순서
1. 실제 브랜드 완제품 비교가 구매에 의미 있으면 **제품 TOP3**.
2. 브랜드 비교가 의미 없는 원물이라면 **산지·지역·품종 TOP3** 가능 여부를 검토.
3. 순위는 판매량·리뷰 수만으로 정하지 않는다.
4. 제품은 핵심성분/함량, 가격 효율, 당류·나트륨·첨가물, 편의성, 정보 투명성을 종합한다.
5. 원물은 생산환경, 산지 전문성, 선별·품질관리, 대표 품종/어종, 유통·신선도, 실제 구매 차이를 종합한다.
6. 직접 비교자료가 없으면 지역별 영양성분 우열을 단정하지 않는다.
7. 반드시 `편집 추천`임을 밝히고, 왜 1·2·3위인지와 누구에게 맞는지 설명한다.
8. 추천 정보를 추가해도 본문 전체 양식을 바꾸지 않는다.

## 6. 음식별 작성 전 체크
- 이 음식의 **대표 영양소/고유 성분 3~8개**를 먼저 적는다.
- 독자가 실제 구매 시 구분하는 형태·품종·크기가 있는지 확인한다.
- 영양 차이가 크면 비교표를 만든다.
- ③에는 실제 신체 변화 4~6개를 음식 특성에 맞게 선정한다.
- ④에는 구체 음식 4개 안팎을 선정하고 이유·맛·실제 먹는 법까지 쓴다.
- ⑤는 행동이 바뀌는 주의만 남긴다.
- ⑥은 고르는 법·보관법 + 제품 TOP3 또는 산지/품종 TOP3 가능 여부를 검토한다.
- 강조는 문장 작성과 동시에 넣고, 마지막에 **형광펜만 위에서 아래로 읽어도 관계와 의미가 빠르게 예측되는지** 다시 확인한다.

## 7. 완료 전 최종 질문
- 제목에 들어간 대표 영양소가 ②에 실제 수치로 들어갔는가?
- 기본 영양만 있고 음식 고유 핵심 영양이 빠지지 않았는가?
- 한 가지 형태의 수치만 제시해 실제 구매 형태 차이를 놓치지 않았는가?
- 표 아래에 수치 해석이 있는가?
- 형광펜이 앞부분부터 끝까지 고르게 있는가?
- 형광펜이 긴 서술문이 아니라 **2~4개 의미 단위의 짧은 키워드 조합**인가?
- 형광펜을 몇 개만 읽어도 `무엇이 → 어떤 의미인지` 빠르게 예측되는가?
- 음식명을 매 강조마다 기계적으로 반복하지 않았는가?
- 승인된 카드·표·박스 디자인을 그대로 유지했는가?
- 완제품 또는 산지/품종 TOP3가 이 음식에서 실제로 유용한지 검토했는가?
- `PUBLIC_VERIFIED`와 원장 상태까지 확인했는가?
