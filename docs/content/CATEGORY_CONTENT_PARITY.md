# 음식 기반 네 카테고리 공통 작성 계약 — 2026-10-10

음식에서 승인된 직접 작성 구성·디자인을 음식·영양소·약학·질병에 동일하게 사용한다. 신규 글과 기존 URL의 전체 재작성 모두 적용한다. 바뀌는 것은 주제에 맞는 내용과 소제목이다. 실제 category 이름을 유지한다. 약은 기존 ‘약학’ 카테고리에 저장한다.

## 동일하게 사용하는 기반

- DIRECT_AUTHORING_R1의 1단계 strong, 2단계 mark+strong, 3단계 mark+u+strong을 작성 중 함께 적용한다. 핵심 수치·역할·작용·조건·실천 행동을 강조하며 카테고리별 다른 강조 규칙이나 할당량을 만들지 않는다.
- 같은 direct-design 렌더러, CSS, 목차·번호·표·카드·대표 이미지·PC/모바일 배치를 사용한다. 사진은 주제와 관련된 기존 사진 또는 유효한 검토 자료를 활용하며 내용 없는 장식 사진을 억지로 채우지 않는다.
- 같은 여섯 핵심 역할 뒤에 FAQ와 핵심 정리를 둔다. 자료출처·이미지 권한·내부링크 기록도 기존 계약을 따른다. 근거를 본문 사이에 큰 카드로 반복하지 않는다.
- 승인된 direct-* 원고와 SP1 계약, posts 신규 발행 및 updates 기존 URL 수정 경로를 그대로 사용한다. 같은 러너·준비 검사·강조 관찰·제출·익명 공개 검증·원장을 사용한다.
- category마다 새 Actions, 러너, AI 재작성 루프, 별도 승인·로컬 브라우저 의무를 추가하지 않는다. 일반 Chat은 조사·원고 저장·기존 실행 결과 관찰을 수행하고 러너가 실제 제출과 공개 검증을 담당한다.
- 기존 변경 없는 R1/R3/R4·legacy 원고의 계약은 유지한다. 이 기준으로 과거 글을 자동 재작성하거나 발행하지 않는다.

표는 역할 대응이지 모든 글의 제목을 고정하는 문구가 아니다. 독자 질문과 실제 본문에 맞게 표시 소제목을 선택한다. 약·질병에 음식의 ‘제철·해감·궁합’을 그대로 복사하지 않는다. 기능성 추출물에 결핍증을 억지로 만들거나, 질병에 보관법을 넣지 않는다. 네 번째 카드 배치의 CSS 이름 pairs는 디자인 이름이며 약효 증강·치료 시너지의 근거가 아니다.

## 문체·의미·안전

소개와 효과는 확인된 특징·역할·도움을 먼저 설명한다. 각 문단마다 부정·반박·한계 문장을 반복하지 않는다. FAQ는 실제 질문에 직접 답하며 핵심 정리는 실천 기준을 요약한다. 제목이 약속한 중심 질문을 도입과 해당 항목에서 직접 답한다.

영양소의 정상 기능과 보충제의 추가 효과를 구분하고 기준량·단위·대상·제품 상태를 표시한다. 약은 국내 공식 허가사항의 정확한 제품·용법·금기·상호작용을 확인한다. 질병은 진료지침·공식 자료의 진단과 치료 범위를 따른다. 확인된 근거 없이 치료·예방·약효 증강·고용량 섭취를 약속하지 않는다. 개인별 진단이나 처방 변경을 대신하지 않는다.

실제 위험·금기·응급 행동은 분명히 유지한다. 긴급한 신호는 다섯 번째 항목에만 숨기지 않고 필요한 경우 도입에도 간결하게 표시한다. 약의 주요 상호작용은 네 번째 활용 항목에서도 해당 행동과 함께 알린다. 긍정적 문체를 이유로 필요한 경고를 삭제하지 않는다.

저장 전 한 번: 제목/소제목과 내용 대응, 여섯 역할, 실제 근거, 단계별 강조·표·내부링크·사진을 함께 확인한다. 준비 출력은 작성자에게 질문을 제공할 뿐 자동 의미 PASS가 아니다. 기술 CI·PUBLIC_VERIFIED는 반영 및 렌더 검증이며 의학적 감수를 뜻하지 않는다.
