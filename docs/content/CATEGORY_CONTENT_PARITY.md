# 네 카테고리 공통 디자인·발행 계약 — 2026-10-12

네 카테고리는 승인된 렌더러·강조·이미지·검증·발행 기반을 공유한다. 각 분야는 사용자가 정한 6개 질문 축을 기본 소주제로 삼고, 실제 제목·검색 의도에 맞게 구체화한다. 음식 목차를 다른 분야에 복사하지 않고 분야별 전용 질문을 적용한다. 실제 category 이름을 유지한다. 약은 기존 ‘약학’ 카테고리에 저장한다.

## 동일하게 사용하는 기반

- DIRECT_AUTHORING_R1의 1단계 strong, 2단계 mark+strong, 3단계 mark+u+strong을 작성 중 함께 적용한다. 핵심 수치·역할·작용·조건·실천 행동을 강조하며 카테고리별 다른 강조 규칙이나 할당량을 만들지 않는다.
- **네 카테고리 공통 최소 강조량은 `strong` 18개 이상, `mark` 8개 이상, `mark > u > strong` 2개 이상이다.** 2·3단계 강조 안의 `strong`도 굵은 글씨 효과에 포함한다. 이 수치는 목표 개수가 아니라 누락 방지용 하한이다. 의미 없는 문장·수치·경고를 추가해 개수만 채우지 않는다.
- **강조는 부정성의 크기가 아니라 독자가 얻는 핵심 정보와 행동의 중요도 순으로 선택한다.** 음식·영양소는 확인된 장점·핵심 성분·신체 작용·실제 섭취/선택 행동을 먼저, 약학은 허가 효능·작용·복용 행동을 먼저, 질병은 증상 이해·치료 목표·생활 관리 행동을 먼저 강조한다. `근거가 부족하다`, `자료가 충분하지 않다`, `단정하기 어렵다`, `입증되지 않았다` 같은 일반적인 근거 한계 문구는 원칙적으로 평문으로 둔다.
- 알레르기·독성·금기·중대한 약물 상호작용·응급 신호처럼 **독자가 실제로 피하거나 즉시 행동해야 하는 안전정보는 강한 강조가 가능하다.** 긍정적인 문체를 이유로 필요한 안전 경고를 약화하거나 삭제하지 않는다.
- 새 direct-* SP1 제출에서는 일반 근거 한계를 형광펜으로 강조하면 `E_DIRECT_EMPHASIS_LIMITATION`, 핵심 장점·작용·실천 영역의 형광펜이 하나도 없고 주의·위험 영역에만 강조가 몰리면 `E_DIRECT_PRIMARY_EMPHASIS_MISSING`으로 편집기 진입 전에 차단한다. 공통 최소량보다 적으면 굵은 글씨는 `E_DIRECT_EMPHASIS_BOLD_MIN`, 하이라이트는 `E_DIRECT_EMPHASIS_HIGHLIGHT_MIN`, 밑줄+하이라이트는 `E_DIRECT_EMPHASIS_UNDERLINE_MIN`으로 차단한다. 이 검사는 문장을 자동 생성하거나 의료적 의미를 자동 판정하지 않는다.
- 같은 direct-design 렌더러, CSS, 목차·번호·표·카드·대표 이미지·PC/모바일 배치를 사용한다. 사진은 주제와 관련된 기존 사진 또는 유효한 검토 자료를 활용하며 내용 없는 장식 사진을 억지로 채우지 않는다.
- 카테고리별 6개 질문 축은 기본 소주제 설계 기준이다. 각 축을 실제 주제에 맞게 구체화하고 검색 의도에 맞는 H2를 최대6개 둔다. 질문에 맞지 않거나 근거가 없는 세부 주장·개수·기간은 억지로 만들지 않고 해당 부분을 조정하거나 생략한다. FAQ와 핵심 정리는 실제 독자 질문과 실천 요약이 있을 때 둔다. 자료 출처·이미지 권한·내부링크 기록은 기존 계약을 따른다. 근거를 본문 사이에 큰 카드로 반복하지 않는다.
- 승인된 direct-* 원고와 SP1 계약, posts 신규 발행 및 updates 기존 URL 수정 경로를 그대로 사용한다. 같은 러너·준비 검사·강조 관찰·제출·익명 공개 검증·원장을 사용한다.
- category마다 새 Actions, 러너, AI 재작성 루프, 별도 승인·로컬 브라우저 의무를 추가하지 않는다. 일반 Chat은 조사·원고 저장·기존 실행 결과 관찰을 수행하고 러너가 실제 제출과 공개 검증을 담당한다.
- 기존 변경 없는 R1/R3/R4·legacy 원고의 계약은 유지한다. 이 기준으로 과거 글을 자동 재작성하거나 발행하지 않는다.

## 음식 궁합의 우선 기준 — 성분 간 상호작용·시너지

- 음식 궁합의 **핵심 질문**은 ‘A의 어떤 성분과 B의 어떤 성분이 함께 있을 때, 흡수·대사·생리 작용에서 어떤 상호작용을 일으키는가?’이다. 본문은 **성분/조건 → 작용 기전 → 실제 관찰된 결과 → 적용할 양·식사 조건** 순서로 설명한다.
- **직접 입증된 사람 대상 조합 연구**, **확인된 일반 흡수·대사 기전의 식품 적용**, **시험관·동물 연구 또는 기전 가설**을 구분한다. ‘시너지’는 확인된 상호작용에 걸맞은 수준으로 표현한다. 단순 병용이나 효과의 합을 검증 없이 임상적인 상승효과로 부르지 않는다.
- **영양소를 서로 채우는 구성, 맛·향 보완, 조리상의 조화만 있는 경우에는 궁합의 핵심 근거로 사용하지 않는다.** 필요하면 해당 내용을 일상 식사 활용에 보조로 배치하되, 확인된 상호작용 없이 ‘효능 강화’나 ‘흡수 증가’라고 표현하지 않는다.
- 특정 음식 두 가지의 직접 연구가 없을 때에는 **기존에 입증된 영양소 수준의 상호작용을 음식에 적용한 설명**인지 분명히 밝힌다. 고농축 추출물·보충제 결과를 평소 먹는 음식 양의 직접 효과로 옮기지 않는다.
- 근거 있는 조합이 적으면 개수를 채우거나 가상의 시너지를 만들지 않는다. 제목과 표시 소제목도 실제로 설명 가능한 상호작용의 범위에 맞춘다. 이 원칙은 작성자 내용 판단이며 새로운 자동 판정·CI 게이트를 만들지 않는다.
- 약학·질병도 네 번째 공통 디자인을 사용하지만 **허가된 병용·상호작용과 의학적 안전**이 우선이다. 음식의 시너지 명칭이나 기전을 약효 상승의 근거로 옮기지 않는다.

## 문체·의미·안전

소개와 효과는 확인된 특징·역할·도움을 먼저 설명한다. 각 문단마다 부정·반박·한계 문장을 반복하지 않는다. FAQ는 실제 질문에 직접 답하며 핵심 정리는 실천 기준을 요약한다. 제목이 약속한 중심 질문을 도입과 해당 항목에서 직접 답한다.

영양소의 정상 기능과 보충제의 추가 효과를 구분하고 기준량·단위·대상·제품 상태를 표시한다. 약은 국내 공식 허가사항의 정확한 제품·용법·금기·상호작용을 확인한다. 질병은 진료지침·공식 자료의 진단과 치료 범위를 따른다. 확인된 근거 없이 치료·예방·약효 증강·고용량 섭취를 약속하지 않는다. 개인별 진단이나 처방 변경을 대신하지 않는다.

실제 위험·금기·응급 행동은 분명히 유지한다. 긴급한 신호는 특정 소주제에만 숨기지 않고 필요한 경우 도입에도 간결하게 표시한다. 약의 주요 상호작용은 해당 주제의 설명에서도 행동과 함께 알린다. 긍정적 문체를 이유로 필요한 경고를 삭제하지 않는다.

저장 전 한 번: 제목과 실제 독자 질문, 각 소제목과 본문 답변의 대응, 해당 글에 필요한 근거·안전·실천 정보, 단계별 강조·표·내부링크·사진을 확인한다. 여섯 질문 축을 기계적으로 복사하거나 근거 없는 세부 주장을 채우지 않는다. **강조된 문구만 따로 훑었을 때 독자가 먼저 보게 되는 것이 핵심 장점·작용·치료/관리 목적·실천 행동인지 확인한다. 일반적인 근거 한계가 핵심 강조를 차지하면 평문으로 낮추고, 실제 안전 행동만 필요한 강도로 남긴다.** 준비 출력은 작성자에게 질문을 제공할 뿐 자동 의미 PASS가 아니다. 기술 CI·PUBLIC_VERIFIED는 반영 및 렌더 검증이며 의학적 감수를 뜻하지 않는다.
