# 분야별 작성·선택 안내 R1

이 문서는 CONTENT_STANDARD_R1의 세부 편집 기준이다. 모든 예시는 **조사해야 할 질문**이며 특정 건강효과·제품 우월성을 확인했다는 뜻이 아니다. 실제 글에서는 해당 시점의 원문·허가사항·제품·산지 자료를 확인한다.

## 음식: 영양을 실제 한 끼와 구매 선택으로 연결

**먼저 답할 질문:** 어떤 음식인지, 내 식사에 어떻게 활용할지, 적당한 분량과 영양 수치, 보관·조리·주의할 상황이다. 100g 수치만 주지 말고 가식부·1개 크기·한 번 먹는 양의 조건을 함께 설명한다. 생것·삶은 것·말린 것·즙·가당 가공품을 같은 음식으로 뭉뚱그리지 않는다. 음식 하나를 꾸준히 먹은 효과를 전체 식단·열량·대체 식품과 분리해 단정하지 않는다.

**품종·산지·계절:** 사과·배의 경우 품종, 맛·신맛·아삭함·향, 주로 유통되는 수확 시기, 생과·조리·선물 등 용도를 조사한다. “청송사과”와 “감홍”처럼 산지와 품종이라는 서로 다른 분류를 경쟁 품종처럼 표에 놓지 않는다. 같은 품종·숙도·보관 조건을 비교할 수 있는지 밝힌다. 산지의 홍보 설명은 해당 기관의 설명으로 표시하며 모든 상품의 당도나 품질을 보장하지 않는다. 특정 지역의 건강효과 우월성은 별도의 건강 근거 없이는 쓰지 않는다.

**고르는 법:** 색 하나로 판별하지 말고 품종별 성숙 특성, 단단함, 상처·부패, 포장 표기, 실제 배송·보관 조건 중 해당 음식에 의미 있는 것을 설명한다. 당도·크기·등급·못난이 여부·저장기간·가격의 차이를 건강상 가치와 구분한다. 가격을 다루면 같은 중량·가식부·배송비·시점으로 비교한다.

**함께 먹는 식사와 대안:** 맛·포만감·먹기 편함·식단 영양 보완을 구분한다. 과일+다른 음식이 특정 질병을 치료한다는 무근거 조합을 만들지 않는다. 다른 과일과 비교할 때 칼로리·당·섬유질 등의 동일 분량과 용도를 맞춘다. 가공품은 원물과 수분·당류·섭취량 차이를 확인한다.

**다른 분야 연결:** 주요 영양소의 몸속 역할을 쉽게 설명한다. 해당 질환·복용약 때문에 실제로 선택이 달라지는 경우만 주의·대안과 함께 다룬다. 알레르기·상한·부패와 같은 중요한 안전정보는 식사 제안 가까이에 둔다. 질환 때문에 모든 독자가 그 음식을 피해야 한다는 인상을 주지 않는다.

**사과 종합글 검토 질문:** 영양/1회분 → 식생활 활용 → 품종·산지 차이 → 제철·고르는 법 → 보관 → 다른 과일 비교 → 같이 먹는 식사 → 개인별 주의와 다음 선택. 지역 목록을 길게 나열하기보다 실제 선택이 달라지는 이유를 쓴다.

## 영양소·기능성 성분: 필요성과 제품 차이를 함께 설명

필수영양소와 선택적 기능성 성분을 구분한다. 성분이 몸에서 하는 정상 역할과 추가 보충제가 주는 효과도 구분한다. “항산화”라는 단어만 쓰지 말고 무슨 뜻인지, 체감 변화인지 연구 지표인지, 어떤 사람에게 의미가 있는지 설명한다. 결핍이 없는 사람에게 더 먹으면 더 건강해진다고 확대하지 않는다. 결핍증이 없는 추출물에 결핍 소제목을 억지로 만들지 않는다.

**양·방법:** 한국 기준 권장량/충분섭취량/상한섭취량, 기능성 원료의 일일섭취량, 연구 용량, 제품 표시량을 분리한다. 원료 총량과 유효성분 또는 원소량을 구분한다. 해외 자료만으로 한국 제품의 공식 복용법을 덮어쓰지 않는다. 실제 근거 없는 공복/식후·나눠 먹기·휴지기 처방을 만들지 않는다.

**장기 섭취:** 단기 연구기간과 장기 안전성을 구분하며 관찰할 변화·필요한 검사·이상반응·재평가 질문을 제시한다. 특정 기간을 먹으면 누구나 좋아지는 달력형 약속은 금지한다. 약 대신 복용하거나 임의로 처방약을 중단하는 결론으로 이어지지 않는다.

**제품 선택은 성분별로 달라진다. 다음 항목을 조사한다:**

| 주제 | 실제 확인할 선택 차이 | 피해야 할 단순화 |
| --- | --- | --- |
| 비타민C | 1회/하루 실제 함량, 원료·제형, 정제/분말/구미, 추가 당·나트륨·칼슘, 중복, 내약성, 같은 조건 비용 | 고함량·리포좀·비싼 제품이 무조건 더 좋은 건강효과 |
| 오메가3 | EPA/DHA 실제 함량, 목적에 맞는 구성, 포장·보관·품질 자료, 복합성분, 1일 비용 | 캡슐 전체 기름 무게를 유효성분량으로 제시 |
| 마그네슘·철 | 실제 원소량, 형태·제형, 섭취 목적, 부작용·기존 복용약, 결핍 판단 | 원료화합물 무게를 원소량으로 오인 |
| 비타민D | 표시 단위, 종류·복합성분, 중복, 검사·필요성 맥락 | 혈중 상태와 무관한 일괄 고용량 선택 |
| 프로바이오틱스 | 목적과 일치하는 균주·제품 연구, 보관 조건, 실제 표시사항 | 균수만으로 모든 제품 순위 확정 |
| 피크노제놀 | 실제 원료·상표·표준화, 인정 기능성과 제품량, 연구 원료와 일치, 다른 추출물과 차이 | 소나무껍질추출물이라는 이름만 같으면 동일 효과 |

이 표는 특정 형태의 임상적 우월성을 선언하지 않는다. 흡수·혈중 지표 차이가 확인되더라도 실제 독자가 원하는 결과의 차이인지 별도 확인한다. 비교에는 대상·분량·기간·직접 비교 여부를 명시한다. 구매 추천이 필요 없는 글은 판매 순위를 넣지 않는다.

**병용·대체:** 실제 추가 도움이 확인된 조합, 단순히 함께 먹을 수 있는 조합, 중복·상호작용 위험을 나눈다. 음식으로 어느 정도 공급할 수 있는지 구체적 분량과 제약을 알려준다. 대체 성분은 목표·효과 근거·안전성을 비교하되 치료 대체를 약속하지 않는다.

## 약: 정확한 제품과 현재 증상을 먼저 연결

브랜드만 같아도 성분·함량·제형·대상·투여 경로가 다를 수 있으므로 정확한 제품을 정한다. 종합 안내라면 여러 종류를 구분하고 임의의 한 제품 용량을 전체에 적용하지 않는다. 국내 허가사항의 효능·용법·금기·중요한 경고를 확인하고 공식 자료에서 찾을 수 없는 내용은 만들어 채우지 않는다.

**실제 사용:** 어떤 증상에 어떤 성분이 맞는지, 어떤 상황에는 맞지 않는지, 효과 시작·지속과 사용기간의 차이를 설명한다. 복용을 놓쳤거나 더 먹었을 때는 해당 제품의 공식 안내를 확인한다. “하루 두 번”을 근거 없이 아침·취침 전으로 정해주지 않는다. 모든 약에 공통으로 두 배 복용·중단·교체를 권하지 않는다.

**감기약 종합글:** 증상별 성분 → 종합약/단일성분 차이 → 성분 중복 확인 → 먹기 편한 식사·음료 → 배즙·꿀 같은 생활 방법의 기대 범위 → 영양제 추가 가치·주의 → 집에서 관리 → 호전 경과·진료 기준. 식사와 보조 방법이 약효를 증강하는지, 단지 수분·섭취 편의·증상 완화에 관련되는지 구분한다. 실제 연구·허가 조건이 없는 조합은 “좋은 궁합”으로 광고하지 않는다.

**비교·대체약:** 같은 적응증·대상·제형·허가 범위로 비교한다. 일반약 구매 기준과 처방약 치료 선택은 다르다. 처방약은 의료진과 검토할 선택지로 설명하며 직접 바꾸라고 하지 않는다. 브랜드 순위보다 성분표·복합성분·중복·복용 편의·주의사항을 먼저 알려준다.

**안전:** 흔한 불편과 심각한 이상반응을 분리한다. 중요한 금기·병용·임신/수유/어린이/고령자 조건은 실제 허가사항에 맞춘다. 위험 안내는 단호하게 쓰되 독자를 비난하지 않는다. 약을 먹고 어떤 변화가 있으면 약사·진료·응급 도움으로 넘어가야 하는지 행동을 명시한다.

## 질병: 확진을 대신하지 않고 안전한 다음 단계로 연결

증상의 위치·양상·시작·기간·변화·동반 증상을 일상어로 설명한다. 유사 증상과 다른 원인이 있을 수 있음을 말하고 확진에는 어떤 검사와 평가가 필요한지 알려준다. 증상 체크만으로 개인의 질병 확률을 계산하거나 “몇 개 이상이면 이 병”이라는 임의 기준을 만들지 않는다.

**우선순위:** 응급신호가 있는 질환은 해당 신호와 즉시 취할 행동을 서두에서 찾기 쉽게 한다. 비응급 상태에는 관찰기간·진료 기준·진료과를 안내한다. 정상/이상 수치를 다룰 때 검사 종류·단위·대상·판정 한계를 빠뜨리지 않는다.

**치료·자가관리:** 표준치료의 목표와 옵션, 가정에서 할 수 있는 일, 피해야 할 행동을 구분한다. 약·시술을 임의로 중단하도록 권하지 않는다. 식사·운동·수면·증상 관찰은 해당 질환과 단계에 맞는 범위에서 구체적으로 쓴다. “몸에 좋게 먹고 운동하세요” 같은 공통 문장만 반복하지 않는다.

**음식·영양제·민간요법:** 보완 방법을 실제 연구·안전성과 연결한다. 자연적인 재료라는 이유로 안전하거나 치료적이라고 말하지 않는다. 표준치료를 대체하거나 진료를 늦추는 방법은 권하지 않는다. 근거 부족을 말할 때는 안전한 대안이나 확인할 행동까지 제시한다.

**경과:** 증상이 나아지는 것과 질환이 치료된 것은 같지 않을 수 있다. 경과·재발·장기 관리·관찰 지표를 구분하고 시간표를 단정하지 않는다. 검사·치료 선택의 최종 결정은 환자의 상태를 아는 의료진의 평가가 필요한 경우임을 설명한다.
