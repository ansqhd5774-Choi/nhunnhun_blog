## IndexNow 지원 범위

[IndexNow 공식 규격](https://www.indexnow.org/documentation)은 같은 호스트의 UTF-8 키 파일을 요구하고, 하위 경로 키의 적용 범위를 해당 경로로 제한한다. [Tistory 공식 스킨 파일 구조](https://tistory.github.io/document-tistory-skin/common/files.html)는 추가 자산을 images에 두며 공개 스킨 자산은 실제 tistory1.daumcdn.net에서 제공된다. 현재 검증한 관리자 기능에서는 숫자 글의 원래 호스트 루트에 키 텍스트 파일을 제공하는 경로를 확보하지 못했다.

따라서 키 업로드나 허위 keyLocation 제출을 하지 않았다. Tistory 전체가 영구적으로 지원 불가능하다고 단정하지 않고, 제공 경로 미확인으로14번을 유지한다. 사이트맵·공식 검색 관리 경로는 계속 사용하며 이 제약을 글 발행 차단 조건으로 추가하지 않는다.
