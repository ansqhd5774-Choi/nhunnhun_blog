# 한입 건강 후속 운영 점검

대상은 https://nhunnhun.tistory.com/ 이다. 쿠폰 사이트의 오류 집계를 가져오지 않았다. 기술 검사, 공개 화면, 제공자 확인과 내용 감수를 구분한다. 전체 완료를 선언하지 않는다.

## 실제 적용

- 사용자 수동 저장 후 프로필·아이콘의 초록 로고를 관리자 화면에서 확인했다. 공개 파비콘은 HTTP 200이고 준비한 ICO와 바이트가 일치한다.
- 기존 스킨에 `growth-events-20261010.js`를 한 번만 추가했다. 기존 Google 태그를 재사용하며 별도 page_view 태그를 만들지 않는다. 관련 글 이동·출처 클릭·공유 요청·URL 복사 요청 4개 이벤트를 GA4 DebugView에서 확인했다. 공유 클릭을 공유 완료로 해석하지 않는다.
- 기존 태그 설정에서 page_location의 query/fragment와 referrer의 경로를 제외했다. 이벤트는 외부 출처의 hostname과 숫자 글 경로만 전달한다. 검사용 query는 debug_mode 표시에만 사용한다.
- GA4 Developer debug traffic 필터를 테스트 상태로 준비한 뒤 사용자의 ‘활성화’ 승인으로 사용중으로 저장했다. 공식 화면의 ‘활성’을 확인했다. 향후 debug_mode 이벤트 제외이며 과거 데이터 삭제가 아니다. 일반 운영자 방문을 자동 식별한 것도 아니다. 기존 Internal traffic 필터는 변경하지 않았다.
- 현재 홍보 채널은 없다. 향후 UTM 캠페인을 도입하면 승인된 캠페인 항목의 전달과 실제 attribution을 별도로 검증해야 한다. URL 전체 수집을 다시 켜는 방식은 사용하지 않는다.

## 공개 점검

- 숫자 공개 URL 356개: HTTP 오류 0, noindex 0, 서로 다른 canonical 충돌 0, title/description 중복 0, description 누락 0, JSON-LD 파싱 오류 0. 기존 354개 관찰과 새 글·변경 글의 추가 관찰을 합친 스냅샷이며 각 관찰 날짜를 보존했다.
- 같은 URL을 가리키는 본문 내 중첩 canonical 184개는 별도 관찰 사항이다. 이미 확인한 색인 결과를 무효화하거나 과거 글 전체 재발행의 필수 조건으로 삼지 않는다.
- OG 브랜드·URL·제목·설명·대표 이미지 누락/불일치 0. 대표 이미지 356개 중 최초 응답 202인 3개는 제한된 후속 확인에서 모두 200/image로 확인했다. 이미지 관련성·라이선스 인증은 아니다.
- 실제 DevTools viewport PC 1440px / 모바일 390px에서 가로 넘침 0. 처음 사용한 viewport 도구는 실제 폭을 바꾸지 않아 해당 결과를 PASS 근거로 쓰지 않았다.

## 출처 및 이미지

재개 가능한 감사 CLI가 공개 글의 본문 범위에서 889개 고유 출처와 2,209개 고유 이미지를 관찰했다. signed URL·전체 원문·계정 화면은 저장소에 넣지 않는다.

출처 자동 접근 분류: 726 접근 가능/내용 미검토, 20 HTTP 404·410, 22 접근 제한, 11 조회 미확인, 109 도메인 확인 보류, 1 기타 HTTP. 일시 제한 도메인의 URL을 반복 조회하지 않는다.

20개 자동 404 중 USDA 17개는 공식 브라우저에서 실제 자료가 표시됐다. HTTP 관찰을 삭제하지 않고 브라우저 결과와 불일치를 함께 남겼다. ‘죽은 링크 17개’로 보고하거나 정상 주소를 임의 교체하지 않는다. 자료의 존재 확인은 각 주장·수치의 검토 완료가 아니다.

약학정보원 3개는 별도 복구 대상이다. /388·/389의 상품 자료는 사이트 검색을 통해 동일 제품의 정상 원문을 확보했다. /264 PDF는 동일 내용을 입증하는 대체 자료 확인이 남았다. 이 문서 작성 시 공개 글 교체는 미실행이다.

본문 이미지 자동 접근: 2,203 가능, 1 제한, 5 미확인. alt 누락 관찰 61곳. 원고 검토 목록은 126개이며 날짜 미확인은 null로 유지한다. 전체 이미지의 시각적 관련성·출처 라이선스 및 전체 건강 주장의 의미 감수는 미완료다.

## 검색·성능의 남은 문제

- Bing 소유 확인은 완료. 사이트맵 처리 화면은 다시 429/Unknown, 발견 0으로 표시됐다. 이전 Processing 접수를 성공으로 재사용하지 않으며 반복 제출하지 않는다.
- IndexNow는 Tistory 동일 호스트의 키 제공 경로를 확인하지 못했다. 다른 호스트 키로 우회하지 않는다. 두 항목 모두 글 발행 게이트가 아니다.
- Google /88 색인됨, /411 스마트폰 실시간 렌더 및 등록 가능 결과는 유효한 기존 증거다. 사이트 전체 URL별 최종 색인은 미확인이다.
- PageSpeed /282 모바일 단일 실험(2026-10-10 04:25 KST): 성능 44, 접근성 93, 권장사항 96, SEO 92. FCP 5.8s, LCP 7.9s, TBT 10ms, CLS 0.346. 실제 사용자 데이터 없음. 성능 개선 완료·CWV 통과로 보고하지 않는다.
- CLS 상세는 본문 이동 0.322·0.022와 제목 이동 0.002를 기록하고 아이콘 웹폰트를 관련 요소로 제시한다. 이동한 요소만으로 삽입 광고·폰트·스킨 중 단일 원인을 확정하지 않는다. 차단 요청에는 스킨 CSS와 티스토리 플랫폼 CSS/JS가 함께 존재한다. 광고·플랫폼 기능 제거는 수행하지 않았다.

## 재사용 도구와 증거

- `scripts/audit-health-evidence.mjs`: 기존 checkpoint 재개, 본문 한정 출처 매핑, 접근/내용 상태 분리, 도메인 제한, 브라우저 cross-check 병합.
- `scripts/audit-og-assets.mjs`: OG 자산 접근 감사, 문제 자산을 사용하는 공개 글 매핑, signed 주소 출력 제외.
- `scripts/install-growth-events.mjs`: 실제 원본에 최소 추가, 중복·REDACTED·모호한 기존 태그 설정 차단. CLI는 후보 파일 준비이며 실제 적용 버튼을 누르지 않는다.
- 로컬 회귀 297개 PASS. 추가 개인정보 전달 검사 11개 PASS. 원고·workflow·광고·카테고리 변경 없음.
- 루트 작업 폴더 `evidence/health-growth-final-20261010/`에 파비콘 비교, 실제 viewport, GA4 DebugView/필터 활성 화면, HTTP checkpoint 및 단일 PageSpeed 화면을 보존한다. 전체 원자료·스킨·계정 화면은 커밋하지 않는다.

32개 상태는 별도 상태표의 행별 범위로 판단한다. 출처 HTTP 성공을 의학 감수 완료로, 기술 테스트를 검색 색인 완료로 치환하지 않는다.
