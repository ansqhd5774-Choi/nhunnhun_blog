# 로컬 생산기 실행판

NH_MENU.cmd에서 지원 과일 16종의 키워드로 자료 수집·이미지 검사·초안 작성·검토를 진행한다. 지원 목록에 있어도 근거, 서로 다른 이미지 3개, 관련 글 또는 품질 검사를 충족하지 못하면 보류한다. 천도복숭아의 최근 실제 시험은 이미지 2개만 통과해 보류됐다.

worker의 승인·Git 전달·표준 workflow 추적·익명 공개 검증·ledger 대조 연결은 구현되어 있다. 공개 완료 조건을 충족한 경우에만 DONE을 허용한다. 이 연결의 성공·실패 검사는 모의 환경이며 실제 신규 발행과 기존 글 수정 E2E는 미실시다. 현재 enabled=false이며 ESU 확인, 원격 배포, 공통 잠금, 사람 확인 보류 해소, 전체 검토와 운영 시험이 필요하다. 의료·복용량 및 기존 글 자동 수정은 승인 범위에 포함하지 않는다.

실행판은 repository·tools·runtime으로 독립 구성되어 work 폴더에 의존하지 않는다. Node 24.19.0, Ollama 0.35.1, qwen3.5:4b 고정 digest를 사용하며 이 PC는 CPU 추론이다. 기존 작업은 보류 상태를 유지했고 GitHub push·workflow dispatch·Tistory 작성과 수정은 수행하지 않았다.
