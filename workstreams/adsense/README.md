# AdSense 작업

범위: 티스토리 수익 설정과 스킨의 광고 코드/배치, 콘텐츠 겹침, 중복 로딩 검사. 공개 로더 존재와 계정 승인·수익은 별도다. 현재 승인·계정 연결·송출 상태 미확인.
산출물: placements.md, settings-before.md, proposals/, changes/기록. 계정 코드 원문을 보고서나 공개 저장소에 노출하지 않는다.
적용 전 해당 설정·코드 백업. 계정 연결, 신규 코드 삽입, 위치 변경은 별도 사용자 요청 범위에서만 진행한다. 광고 클릭·수익 조작·반복 광고 새로고침 금지.
완료 기준: 승인된 설정 변경과 PC/모바일 배치 검수. 광고가 일시적으로 미노출되면 실제 오류와 구분하며 수익·승인을 보장하지 않는다.
