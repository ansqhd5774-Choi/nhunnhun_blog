# 카테고리 작업

초기 기준(2026-10-02): Life 307 / Healthy Life 305 / 음식 186 / 영양소 111 / 약약 4 / 질병 4. 이 수치는 역사 기록으로 보존한다.

현재 사용자 확정 운영 범위(2026-10-05):
- 음식
- 영양소
- 약학
- 질병

이후 nhunnhun은 위 4개 카테고리를 모두 운영한다. 특정 1개 카테고리 전용으로 제한하지 않는다.

운영 원칙:
- 기존 글의 숫자 URL과 기존 카테고리는 특별한 이유가 없으면 유지한다.
- 신규 글은 검색 의도에 가장 맞는 카테고리 1개를 선택한다.
- 4개 카테고리를 동일 비율로 맞추지 않는다. 검색 수요, 기존 글 중복, GSC 성과, 최신성 필요도를 우선한다.
- 음식 ↔ 영양소 ↔ 약학 ↔ 질병 사이 검색 의도가 겹치면 신규 URL 생성보다 기존 글 최신화를 우선한다.
- 약학·질병은 공식기관, 허가사항, 진료지침, 원문 연구를 우선한다.
- 기존 카테고리 이름 변경·병합·이동은 URL·내부링크 영향을 확인하고 별도 승인 범위에서만 수행한다.

산출물: mapping.csv (글URL, 이전카테고리, 후보카테고리, 이름변경, 링크영향, 승인, 적용, 복구), proposals/, changes/기록.

이름 변경·병합·이동은 현재 구조와 글 소속을 관리자에서 확인하고 매핑표를 만든 뒤 승인 범위에만 적용한다. 삭제는 별도 확인한다. 기존 링크·탐색·글 수를 적용 후 대조한다.
