# 글 디자인 점검 수정

- 스킨 CSS: 모바일 표 가로 스크롤, 단어 강제 분할 해제, 중복 파란 장식 숨김.
- 음식 생성 HTML: 첫 이미지를 소개 앞에 한 번 배치.
- 강조 처리: Markdown 강조 표기를 제거한 원문으로 선택 구절 확인, 한 텍스트 블록의 여러 강조 적용.

검증: 문법 검사 및 3단계 다중 강조 fixture 통과. 실제 /179 PC 1440px·모바일 390px 렌더링 확인. 모바일 표 580px / 래퍼 348px 가로 스크롤, 페이지 가로 넘침 없음. 파란 장식 6개 display:none 확인.

검사 제한: queue-single-pass 기존 검사 8개 중 2개 실패(잘못된 응답·receipt 거부 기대). 이 작업에서 해당 계약은 변경하지 않음. 전체 검사 통과로 보고하지 않음.

운영 범위: 스킨 CSS는 실제 적용. 대표 이미지 배치·추가 강조는 향후 생성 또는 재발행 시 적용. 현재 글 내용과 사진 자체는 변경하지 않음.
