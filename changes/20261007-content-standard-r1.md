## 한계와 이후 운영
코드는 의미를 독립적으로 판단하는 의료 AI가 아니다. PASS는 계약 검사와 실제 편집 검토 기록의 존재·일치를 뜻한다. 글의 임상 정확성·효과·검색수요·독자 만족은 실제 조사와 검토가 필요하다. 새 글 또는 기존 글 수정 시 R1 source+review를 만들어야 한다. 오래된 미검토 pending은 새 규격 없이 공개하지 않는다.

## 복구
문제 발생 시 공개 mutation을 실행하지 않고 해당 통합 commit을 역적용하는 PR을 만든다. 과거 source·ledger를 되돌리거나 force push하지 않는다. 기존 R3 원본/렌더 해시가 회귀 기준이다. 되돌리기 후 기본 테스트와 공개 변경 없는 validation을 확인한다. 이미 이후에 R1 글이 발행된 경우 그 글의 renderer 의존성을 먼저 확인하므로 규격 파일만 무조건 삭제하지 않는다.
